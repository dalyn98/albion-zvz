# 디스코드 로그인

봇이 추가되면 사이트는 봇을 초대한 사람의 디스코드 신원을 확인합니다. 이 사람이 곧 그 길드의 첫 어드민이 됩니다.

## 어떻게 동작하나

디스코드 OAuth 로그인 후 사이트로 돌아오면, 봇 설치자의 디스코드 ID 를 길드의 어드민으로 자동 등록합니다. 첫 어드민은 추후 다른 사람을 어드민으로 임명할 수 있습니다.

## 규칙과 정책

### 첫 어드민은 봇 설치자

봇 설치자는 이미 디스코드 서버 관리 권한을 가진 사람이라 신뢰 기반이 자연스럽게 이어집니다. 별도의 인증 절차 없이 그대로 사이트 어드민으로 인정해, 새 길드가 사이트에서 첫 작업을 곧장 시작할 수 있게 했습니다.
