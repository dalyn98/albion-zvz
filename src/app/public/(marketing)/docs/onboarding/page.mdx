# 봇 초대 & 첫 설정

디스코드 봇을 길드 서버에 초대하고 사이트를 처음 설정하는 흐름입니다. 운영자에게 따로 요청할 필요 없이 길드 관리자가 직접 끝낼 수 있도록 만들어졌습니다.

## 무엇을 할 수 있나

- 새 길드가 봇을 초대해 사이트를 시작
- 길드 전용 주소 (예: `우리길드.albion-guildmanager.com`) 만들기
- 자동 리기어 / 알림 / 보상 정책의 기본값 설정
- 길드원에게 알비온 캐릭터 연결 안내

## 어떻게 동작하나

### 1. 봇 초대

랜딩 페이지의 **"봇 설치"** 버튼을 누르거나, 짧은 주소로 바로 들어갑니다.

```
https://albion-guildmanager.com/invite
```

디스코드 OAuth 화면에서 봇을 추가할 서버를 선택합니다. 봇을 추가하려면 **디스코드 서버에서 "서버 관리" 권한** 이 있어야 합니다.

### 2. 디스코드 로그인

봇이 추가되면 사이트는 봇을 초대한 사람의 디스코드 신원을 확인합니다. 이 사람이 곧 첫 길드 어드민이 됩니다.

### 3. 설정 마법사

자동으로 열리는 마법사를 따라 세 단계를 진행합니다.

1. **기본 정보** — 사이트 주소 (예: `menhera` → `menhera.albion-guildmanager.com`) 와 길드 표시 이름
2. **알비온 홈 길드** — 추적할 알비온 길드를 검색해서 선택합니다 (Americas / Asia / Europe 서버 중 하나)
3. **보상 정책** — 자동 리기어 켜기/끄기, 기본 보상 비율 등. 나중에 어드민 설정에서 언제든 바꿀 수 있습니다.

### 4. 알비온 캐릭터 연결

길드원이 사이트에 처음 들어오면 캐릭터 연결 안내가 뜹니다. 캐릭터 이름을 검색하고 본인 확인 절차를 거쳐 디스코드 계정과 알비온 캐릭터를 1:1 로 묶습니다.

어드민 설정에서 "**캐릭터 미연결 길드원 접속 허용**" 을 끄면, 연결 안 한 사람은 캐릭터 연결 화면으로 자동 안내됩니다.

## 규칙과 정책

### 운영자 개입 없이 시작할 수 있어야 합니다

길드 관리자가 봇을 초대하면 그 시점부터 모든 기능이 곧바로 사용 가능해야 합니다. 새 길드가 시작하기 위해 우리에게 따로 요청을 넣거나 기다릴 필요가 없도록 만들었고, 모든 새 기능은 "봇만 막 초대한 길드" 도 동등하게 쓸 수 있는 상태로 출시됩니다.

### 사이트 주소는 디스코드 길드명과 따로 정합니다

디스코드 길드명은 한글·이모지·띄어쓰기를 허용해서 인터넷 주소에 그대로 쓸 수 없습니다. 그래서 마법사에서 영문 위주의 짧은 주소를 별도로 받고, 화면에 보이는 길드 이름은 그 주소에서 자동으로 만들어 둡니다 (필요하면 어드민에서 따로 바꿀 수 있습니다).

### 캐릭터 연결을 안 한 사람도 통계에 잡힙니다

알비온 길드에 가입했지만 사이트 인증을 미루는 사람이 항상 있습니다. 그들의 킬보드도 추적하지 않으면 길드 통계가 부정확해지므로, 알비온 길드 명단을 기준으로 통계는 잡되 청구·상점 같은 본인 액션이 필요한 기능은 인증한 사람만 쓸 수 있게 분리했습니다.
