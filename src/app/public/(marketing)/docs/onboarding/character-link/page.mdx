# 알비온 캐릭터 연결

길드원이 사이트에 처음 들어왔을 때 본인 디스코드 계정과 알비온 캐릭터를 1:1 로 묶는 단계입니다. 이게 끝나야 청구·상점 같은 본인 액션 기능을 사용할 수 있습니다.

## 어떻게 동작하나

길드원이 사이트에 들어오면 캐릭터 연결 안내가 자동으로 뜹니다. 캐릭터 이름을 검색하고 본인 확인 절차를 거쳐 디스코드 계정과 알비온 캐릭터를 묶습니다.

어드민 설정에서 **"캐릭터 미연결 길드원 접속 허용"** 을 끄면, 연결 안 한 사람은 캐릭터 연결 화면으로 자동 이동됩니다.


## 규칙과 정책

### 디스코드 ↔ 알비온 1:1 연결

길드 운영의 모든 데이터 (청구·통계·업적) 는 한 사람당 한 줄로 정렬돼야 의미가 있습니다. 디스코드만으로는 알비온 활동을 볼 수 없고, 알비온만으로는 청구를 할 수 없습니다. 두 신원을 하나로 묶어야 "이 사람의 이번 주 ZvZ 사망 → 이 청구" 같은 흐름이 자연스럽게 이어집니다.

### 캐릭터 연결을 안 한 사람도 통계에는 잡힙니다

알비온 길드에 가입했지만 사이트 인증을 미루는 사람이 있어도 길드 통계는 정확해야 합니다. 그래서 알비온 길드 명단으로 통계는 잡되, 청구·상점 같은 본인 액션이 필요한 기능은 인증한 사람만 쓸 수 있게 분리했습니다.
