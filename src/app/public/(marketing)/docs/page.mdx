# Albion Guild Manager 사용 안내서

알비온 길드 운영을 한 곳에서 자동화하는 서비스입니다. 디스코드 봇을 길드 서버에 초대하면 이벤트 모집, 킬보드 추적, 자동 리기어 보상, 길드 상점, 통계와 업적까지 하나의 흐름으로 연결됩니다.

AGM 의 목표는 "관리자만 보는 도구" 가 아닙니다. 길드원도 이벤트 링크로 들어와 슬롯을 신청하고, 내 지갑과 리기어 청구 상태를 확인하며, 본인 기록과 순위를 볼 수 있어야 합니다. 이 문서는 길드장이 운영 정책을 정할 때 필요한 기준과, 길드원이 실제로 보게 되는 화면의 의미를 함께 설명합니다.

## 빠른 시작

1. **봇 초대** — 랜딩 페이지의 "내 길드 만들기" 버튼 또는 단축 주소 [`/invite`](/invite) 로 디스코드 서버에 봇을 초대합니다.
2. **첫 설정** — 디스코드 로그인 후 길드 주소, 알비온 홈 길드, 기본 정책 (자동 리기어 등) 을 정합니다.
3. **알비온 캐릭터 연결** — 길드원이 사이트에 처음 들어오면 본인의 알비온 캐릭터를 연결합니다.
4. **첫 ZvZ 후** — 킬보드가 자동으로 들어오고, 블랙존 사망은 리기어 청구가 자동으로 만들어집니다.

## 어떤 순서로 보면 좋나요?

- **처음 도입하는 길드장** — 온보딩 → 관리자 설정 → 이벤트 운영 → 리기어 → 상점/제작 순서로 보세요.
- **길드원에게 안내할 때** — 개인 대시보드 → 이벤트 운영 → 리기어 청구 → 지갑/상점 → 리더보드 순서가 이해하기 쉽습니다.
- **통계 신뢰도를 확인할 때** — 킬보드 추적 → 전투 집계 → 리더보드 문서를 함께 보면 어떤 전투가 포함되고 제외되는지 알 수 있습니다.

## 이 문서가 답하는 질문

길드를 운영하다 보면 "왜 이 청구는 승인 대기로 들어왔지?", "왜 이 전투는 통계에 안 잡혔지?" 같은 의문이 자주 생깁니다. 이 문서는 각 기능의 작동 방식과 함께 **그렇게 정한 이유** 를 같이 적어, 운영하면서 부딪히는 의문을 미리 풀어둡니다.

본 문서는 한국어로 작성되어 있으며 다국어 번역은 순차 진행 중입니다. 사이트(앱) UI 는 한국어 · 일본어 · 영어 · 중국어 (간체) 4개 언어를 모두 지원합니다.
