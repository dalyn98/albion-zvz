# Albion Guild Manager 공식 문서

ZvZ 길드 운영을 자동화하는 멀티테넌트 SaaS 의 공식 사용 안내서입니다. 디스코드 봇 1개를 길드 서버에 초대하면 알비온 킬보드 트래킹·자동 리기어·길드 상점·통계까지 한 번에 사용할 수 있습니다.

## 빠른 시작

1. **봇 초대** — 디스코드 서버에 봇을 초대합니다. 랜딩 페이지의 "봇 설치" 버튼 또는 [`/invite`](/invite) 단축 URL.
2. **첫 셋업** — 디스코드 OAuth 로 로그인 → 길드 슬러그 / 알비온 홈 길드 / 권한 토글을 정합니다.
3. **알비온 인증** — 길드원들이 사이트에 처음 접속할 때 본인 알비온 캐릭터를 연결합니다 (Albion API 검증).
4. **첫 ZvZ 후** — 매 5분 동기화로 킬보드가 들어오고, 블랙존 사망은 자동 리기어 청구가 `pending` 으로 생성됩니다.

## 어떤 게 들어 있나

- **디스코드 봇 + 멀티테넌트 사이트** — 봇 1개, 길드 서버마다 독립적인 데이터·설정.
- **알비온 킬보드 자동 트래킹** — 5분 주기 동기화, 명성·장비·딜러/탱커 분류까지 자동.
- **ZvZ 전투 집계 + 이벤트 리포트** — 10인 이상 자동 집계, 갱크/저참여 자동 컷, 알라이언스별 분리.
- **자동/수동 리기어 청구** — 실버 + 제작 듀얼 모드, 블랙존 한정 자동 생성, 부위별 가격 편집.
- **길드 상점 (포인트 ↔ 실버)** — 환율 = 할인율, 100% 면 1:1, 50% 면 절반 할인 판매.
- **통계 · 업적 · 리더보드** — 무기 카테고리 집계, DPS 제외 생존률 등 hard rule 기반.
- **어드민 설정** — 가격, 권한, 토글, 동기화 주기, 봇 채널 등.

좌측 사이드바의 "기능" 섹션에서 각 기능의 자세한 사용법과 디자인 결정 (왜 이렇게 만들었는가) 을 볼 수 있습니다.

## 이 문서의 톤

기능마다 사용 시나리오와 함께 **"왜 이렇게 만들었나"** 를 적어 둡니다. 자동 리기어를 왜 항상 `pending` 으로 두는지, 킬보드 집계에서 왜 10명 미만을 잘라내는지 등 — 운영하다 부딪히는 의문을 미리 풀어두기 위함입니다.

번역은 한국어 우선. 일본어/영어 본문은 차차 추가됩니다.
