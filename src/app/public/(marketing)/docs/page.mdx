# Albion Guild Manager 사용 안내서

알비온 길드 운영을 한 곳에서 자동화하는 서비스입니다. 디스코드 봇을 길드 서버에 초대하면 킬보드 추적, 자동 리기어 보상, 길드 상점, 통계와 업적까지 모두 사용할 수 있습니다.

## 빠른 시작

1. **봇 초대** — 랜딩 페이지의 "봇 설치" 버튼 또는 단축 주소 [`/invite`](/invite) 로 디스코드 서버에 봇을 초대합니다.
2. **첫 설정** — 디스코드 로그인 후 길드 주소, 알비온 홈 길드, 기본 정책 (자동 리기어 등) 을 정합니다.
3. **알비온 캐릭터 연결** — 길드원이 사이트에 처음 들어오면 본인의 알비온 캐릭터를 연결합니다.
4. **첫 ZvZ 후** — 킬보드가 자동으로 들어오고, 블랙존 사망은 리기어 청구가 자동으로 만들어집니다.

## 어떤 기능이 있나

- **디스코드 봇 + 길드 전용 사이트** — 봇 1개로 길드별로 독립된 사이트와 데이터.
- **알비온 킬보드 자동 추적** — 길드원의 킬·데스를 정기적으로 가져와 사이트에 누적.
- **ZvZ 전투 집계 + 이벤트 보고서** — 한 판마다 참가자·결과 정리, 이벤트(정기 ZvZ 등) 단위 묶음.
- **자동/수동 리기어** — 사망 시 청구 자동 생성, 실버 또는 길드 제작으로 보상.
- **길드 상점** — 포인트로 길드 금고 장비를 살 수 있는 내부 상점, 환율 조정으로 할인 운영.
- **업적 · 통계 · 리더보드** — 무기 사용 패턴, 생존률, 길드 안 순위.
- **어드민 설정** — 가격, 권한, 자동화 토글 등 운영 정책 관리.

좌측 목차에서 각 기능의 자세한 안내와 **왜 이렇게 만들어졌는지** 를 볼 수 있습니다.

## 이 문서가 답하는 질문

길드를 운영하다 보면 "왜 이 청구는 승인 대기로 들어왔지?", "왜 이 전투는 통계에 안 잡혔지?" 같은 의문이 자주 생깁니다. 이 문서는 각 기능의 작동 방식과 함께 **그렇게 정한 이유** 를 같이 적어, 운영하면서 부딪히는 의문을 미리 풀어둡니다.

번역은 한국어 우선이며 일본어/영어는 차차 추가됩니다.
