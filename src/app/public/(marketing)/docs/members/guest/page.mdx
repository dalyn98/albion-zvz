# 게스트 시스템

연합 ZvZ 처럼 다른 길드원이 한두 번 참여하는 이벤트가 있을 때, 그 사람에게 사이트 일부만 볼 수 있는 권한을 임시로 주는 시스템입니다.

## 어떻게 동작하나

게스트는 본인이 참여한 이벤트 페이지만 볼 수 있고, 다른 주소로 들어가면 자기 이벤트 페이지로 자동 이동됩니다. 이벤트가 끝나면 권한이 자연스럽게 만료됩니다.

<DocImage caption="게스트 초대 → 자기 이벤트만 보이는 화면" />

## 규칙과 정책

### 게스트에게 사이트 전체 권한을 주지 않습니다

연합 ZvZ 한 번 같이 한 사람에게 길드 청구 / 상점 / 어드민 데이터까지 보여줄 이유는 없습니다. 사이트 전체 권한을 주면 보안과 운영이 모두 어려워지므로, 자기 이벤트 페이지만 볼 수 있게 격리했습니다.
