# 멤버 관리 & 길드 동기화

디스코드 길드원과 알비온 캐릭터를 1:1 로 묶고, 권한과 상태를 관리하는 영역입니다. 한쪽에서 바뀐 정보가 다른 쪽에 자동으로 반영됩니다.

## 무엇을 할 수 있나

- 새 길드원의 권한과 역할을 부여
- 기존 멤버가 알비온 캐릭터를 변경/추가했을 때 갱신
- 게스트 (특정 이벤트만 참여하는 외부인) 임시 초대
- 알비온 길드를 떠난 사람 정리

## 어떻게 동작하나

### 멤버 목록

`/members` 에 사이트의 모든 길드원이 카드로 나열됩니다.

- 디스코드 닉네임 / 알비온 캐릭터 / 권한 / 마지막 활동
- 이름·권한 (어드민 / 제작자) · 인증 여부로 검색·필터
- 카드를 클릭하면 멤버 상세로 이동

### 멤버 상세

`/members/[디스코드ID]` 에서 한 사람의 종합 정보를 봅니다.

- 알비온 캐릭터 정보 (서버, 길드, 명성, 자주 쓰는 장비)
- 최근 추적된 킬·데스 (스크롤 가능)
- 청구 내역과 보상 합계
- 어드민이라면 권한 토글, 비활성·제명 액션

### 알비온 캐릭터 직접 접근

`/members/albion/[캐릭터ID]` 로 디스코드 닉네임을 모르더라도 알비온 캐릭터로 직접 멤버 페이지를 열 수 있습니다.

### 길드 동기화

- 정기 동기화: 알비온 공식 데이터에서 길드 명단을 주기적으로 가져와 사이트 멤버와 매칭
- 떠난 사람: 알비온 길드에서 빠지면 사이트의 캐릭터 인증이 풀리고, 어드민이 일괄 정리할 수 있습니다
- 새 사람: 알비온 길드에 추가됐지만 사이트 인증을 안 한 사람은 멤버 카드 없이 통계에만 잡힙니다

## 규칙과 정책

### 디스코드 ↔ 알비온 1:1 연결

길드 운영의 모든 데이터 (청구·통계·업적) 는 한 사람당 한 줄로 정렬돼야 의미가 있습니다. 디스코드만으로는 알비온 활동을 못 보고, 알비온만으로는 청구를 못 합니다. 두 신원을 하나로 묶어야 "이 사람의 이번 주 ZvZ 사망 → 이 청구" 같은 흐름이 자연스럽게 이어집니다.

### 게스트 시스템

연합 ZvZ 처럼 외부 길드원이 한 번씩 참여하는 이벤트가 있습니다. 그들에게 사이트 전체 권한을 줄 수는 없으므로, 게스트는 자기가 참여한 이벤트 페이지만 볼 수 있고 다른 주소에 접근하면 자기 이벤트로 자동 이동됩니다.

### 인증 안 한 멤버도 통계에는 잡힙니다

알비온 길드에 가입했지만 사이트 인증을 미루는 사람이 있어도 길드 통계는 정확해야 합니다. 그래서 알비온 길드 명단으로 통계는 잡되, 청구·상점 같은 본인이 액션해야 하는 기능은 인증한 사람만 쓸 수 있게 분리했습니다.

### "어드민" 과 "제작자" 는 별도 권한입니다

사이트 어드민은 운영 정책·승인을 다루는 사람, 제작자는 길드 제작 큐를 처리하는 사람입니다. 두 역할은 보통 다른 사람이 맡으므로 권한도 분리되어 있어, 한쪽만 가진 사람도 자기 영역만 깔끔히 쓸 수 있습니다.
