# 멤버 상세

한 길드원의 종합 정보 화면. 활동·권한·청구 내역이 한 페이지에 모이고, 어드민 액션도 여기에서 합니다.

## 어떻게 동작하나

`/members/[디스코드ID]` 에서 다음 정보를 봅니다.

- 알비온 캐릭터 정보 (서버, 길드, 명성, 자주 쓰는 장비)
- 최근 추적된 킬·데스 (스크롤 가능)
- 청구 내역과 보상 합계
- 어드민이라면 권한 토글, 비활성·제명 액션

알비온 캐릭터로 직접 페이지를 열고 싶을 때는 `/members/albion/[캐릭터ID]` 를 사용합니다 — 디스코드 닉네임을 모를 때 유용합니다.


## 규칙과 정책

### 디스코드 ↔ 알비온 1:1 연결

길드 운영의 모든 데이터 (청구·통계·업적) 는 한 사람당 한 줄로 정렬돼야 의미가 있습니다. 두 신원을 하나로 묶어야 "이 사람의 이번 주 ZvZ 사망 → 이 청구" 같은 흐름이 자연스럽게 이어집니다.
