# 길드 동기화

알비온 공식 데이터에서 길드 명단을 정기적으로 가져와 사이트의 멤버 카드와 매칭하는 영역입니다. 알비온에서 가입·탈퇴가 있어도 사이트가 자동으로 따라옵니다.

## 어떻게 동작하나

- **정기 동기화**: 알비온 공식 데이터에서 길드 명단을 주기적으로 가져와 사이트 멤버와 매칭
- **떠난 사람**: 알비온 길드에서 빠지면 사이트의 캐릭터 인증이 풀리고, 어드민이 일괄 정리할 수 있습니다
- **새 사람**: 알비온 길드에 추가됐지만 사이트 인증을 안 한 사람은 멤버 카드 없이 통계에만 잡힙니다

## 규칙과 정책

### 인증 안 한 멤버도 통계에는 잡힙니다

알비온 길드에 가입했지만 사이트 인증을 미루는 사람이 있어도 길드 통계는 정확해야 합니다. 그래서 알비온 길드 명단으로 통계는 잡되, 청구·상점 같은 본인이 액션해야 하는 기능은 인증한 사람만 쓸 수 있게 분리했습니다.
