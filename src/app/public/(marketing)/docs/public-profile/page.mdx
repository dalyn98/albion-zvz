# 길드 공개 페이지

`/g/<slug>` 주소로 누구나 볼 수 있는 길드 소개·모집 페이지입니다. 어드민이 한 번 켜고 정보를 채우면 SEO 메타데이터와 hero 비주얼까지 자동으로 따라옵니다.

## 어떻게 동작하나

기본 상태는 OFF — 어드민이 길드 공개 프로필 설정에서 `guild_profile_enabled` 를 ON 해야 페이지가 외부에 노출됩니다. ON 이후 같은 페이지 우상단의 "배너 편집" 버튼이나 어드민 설정의 "길드 공개 프로필" 메뉴에서 다음을 조정합니다.

- **배너 이미지 + 투명도** — 21:9 비율 권장. 30 / 50 / 70 / 90 / 100% 중 한 값을 골라 배너 위 어두운 그라데이션과 어우러지는 정도를 조절합니다.
- **강조 색상** — amber / rose / emerald / sky / violet / orange / pink / slate 중 하나. hero 배경, 헤더 강조, 모집 배지, CTA 버튼 색상이 한꺼번에 따라갑니다.
- **소개문 / 모집 상태 / 디스코드 초대** — 자유 텍스트 + open / selective / closed 3 단계. closed 면 모집 카드 자체를 숨깁니다.
- **활동 시간대 / 사용 언어** — hero 칩으로 표시. 사용 언어는 ko / ja / en / zh / es / fr / de / pt 중 다중 선택할 수 있습니다.
- **섹션 단위 토글** — 멤버 수 / 전투 기록 / 무기 분포 / 라이벌 길드 / 운영진 / 활동 / 리기어 통계 / 리더보드 등 노출 항목을 개별로 ON / OFF 합니다.
- **모집 포지션 / 가입 절차 / 정기 이벤트** — 자유 텍스트 카드. 빈 값이면 카드 자체가 자동으로 숨김 처리됩니다.

## 규칙과 정책

### 길드 이름은 알비온 인게임 영문명 우선

공개 페이지의 H1·페이지 타이틀·SEO 메타데이터는 항상 알비온 인게임 길드명 (영문) 을 우선해서 보여줍니다. 알비온은 길드명에 영문만 허용하기 때문에, 다른 플레이어가 검색하거나 킬보드에서 추적하는 이름과 그대로 일치시키기 위함입니다. Discord 의 한국어 / 일본어 / 중국어 길드명은 어드민 운영 surface 안쪽에서만 사용됩니다.

### 배너 투명도는 텍스트 가독성을 깨지 않습니다

배너 이미지의 투명도를 100% 까지 올려도 hero 영역 위에는 항상 어두운 그라데이션이 한 겹 더 깔립니다. 배너가 너무 환하면 길드명 / 모집 배지 / CTA 버튼이 묻혀 SEO·마케팅 surface 가 무너지므로, 가독성을 보호하는 베이스라인은 어드민 토글로도 끄지 못하게 했습니다.

### 첫 설정 후 홈 길드는 슈퍼어드민만 변경

길드 등록 후 알비온 홈 길드를 자유롭게 바꾸면 SEO·공개 페이지·킬보드 매칭이 매번 깨집니다. 첫 설정에서 한 번 잠그고, 이후 변경은 슈퍼어드민(운영자) 에게 문의하도록 했습니다.

### 모집 카드 / 가입 절차 / 정기 이벤트는 빈 값이면 숨김

운영을 막 시작한 길드가 모든 카드를 빈 값으로 띄우면 페이지가 부실해 보이고 SEO 점수도 떨어집니다. 자유 텍스트 카드들은 값을 채울 때만 노출되도록 해서, 채워진 정보만으로 페이지를 깔끔하게 보여줍니다.
