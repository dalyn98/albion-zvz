# 어드민 승인

청구가 제출되면 어드민 승인 큐로 들어갑니다. 어드민은 가격 적정성과 이상 정황을 보고 승인 또는 반려합니다.

## 어떻게 동작하나

어드민 승인 큐에서 청구를 한 줄씩 펼쳐 봅니다.

- 청구된 장비와 부위별 가격
- 시스템 추정 시세와의 차이
- 자동으로 표시되는 이상 정황 (anomaly) 마크
- 사망 스크린샷 / 검증 결과

승인하면 청구자에게 보상이 즉시 지급되거나 (실버) 제작 큐로 전달됩니다 (제작 모드).


## 규칙과 정책

### 2단계 흐름이 신뢰성과 책임의 균형점

청구자 본인이 자기 빌드를 한 번 검토 → 어드민이 가격·정황을 확인의 2단계 흐름은 양쪽 모두 책임 분담이 명확합니다. 자동 매칭이 그대로 승인까지 가면 분쟁이 잦아지고, 모든 청구를 어드민이 처음부터 입력하게 하면 어드민의 부담이 너무 큽니다.
