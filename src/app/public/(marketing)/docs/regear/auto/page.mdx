# 자동 리기어

블랙존 ZvZ 에서 사망이 추적되면 시스템이 자동으로 청구를 만듭니다. 청구자는 본인이 한 번 검토·편집하고 제출하면 됩니다.

## 어떻게 동작하나

- 처음 상태는 항상 **승인 대기** — 청구자가 직접 검토하고 부위별 가격을 편집한 뒤 제출합니다
- 자동 생성 자체는 정기 작업이 돌리며, 어드민이 자동 리기어 토글을 끄면 정기 작업도 멈춥니다
- 청구 화면에서 6개 슬롯 (무기 / 머리 / 갑옷 / 신발 / 보조무기 / 망토) 의 가격을 각각 조정할 수 있습니다


## 규칙과 정책

### 자동 리기어도 본인이 한 번 검토합니다

자동 매칭이 곧장 승인까지 처리하면 청구자가 자기 빌드·가격을 통제할 수 없어 "내 빌드는 더 비싼데?", "이 부위는 왜 빠졌나?" 같은 분쟁이 생깁니다. 청구자 본인이 한 번 손대고 제출 → 어드민 승인의 2단계가 신뢰성과 책임의 균형점입니다.

### 자동 리기어는 블랙존만

레드존·옐로우존·블루존 사망은 ZvZ 가 아니라 갱크나 실수가 대부분입니다. 자동 청구가 잘못 잡히는 비용이 너무 커서 블랙존만 자동화하고, 그 외는 멤버가 의식적으로 수동 청구하도록 했습니다.

### 부위별 가격 편집을 허용합니다

같은 T8 갑옷이라도 인챈트·아티팩트가 다르면 시장 가격이 매번 변합니다. 시스템 추정 가격을 그대로 쓰면 청구자가 손해를 보거나 길드가 과지급하는 일이 자주 생기므로, 청구자가 자기 빌드의 시점 가격을 직접 입력하는 게 가장 정확합니다.

## 시스템 추정 가격은 어떻게 정해지나

자동 청구가 만들어질 때 보이는 1차 가격은 AODP (Albion Online Data Project — 플레이어들이 게임에서 수집한 거래 시세를 공유하는 공개 데이터) 를 기반으로 산정합니다.

### 기준 도시 1순위 + 다른 로열 도시 중앙값 폴백

길드가 어드민 설정에서 고른 **기준 도시** (Caerleon, Bridgewatch, Lymhurst, Martlock, Fort Sterling, Thetford 중 하나) 의 최근 시세를 1차로 씁니다. 기준 도시에 시세가 없거나 너무 오래된 경우, 나머지 로열 도시들의 거래 시세를 모아 **가중 중앙값** 으로 폴백합니다. 인게임에서 실제로 보이는 추정가에 가장 가까운 값을 만들기 위한 두 단계 안전망입니다.

### 품질 축은 시세에서 제거

같은 (uniqueName, 인챈트) 조합이면 노멀 / 굿 / 아웃스탠딩 / 엑설런트 / 마스터피스 모두 같은 단가로 보여줍니다. 품질이 위로 올라갈수록 인게임 거래 가격은 비싸지지만 ZvZ 리기어 보상 정책상 품질 차이를 일일이 따지면 운영이 복잡해지고 청구자/어드민 모두 피곤해지므로, 길드 보상 시세는 품질 축을 제거하고 일관된 단가로 운영합니다 (인벤토리 행은 품질별로 보존됩니다).

### 신뢰도 낮은 슬롯 자동 제외 (어드민 토글)

AODP 시세 데이터가 너무 오래되거나 표본이 적은 슬롯은 추정 가격이 실제와 크게 어긋날 수 있습니다. 어드민 설정에서 "신뢰도 낮은 슬롯 자동 제외" 토글을 켜면, 자동 청구가 만들어질 때 데이터가 빈약한 슬롯을 0원이 아니라 **청구 항목에서 아예 빼서** 만듭니다. 청구자가 그 슬롯을 직접 추가하거나 빌드를 다시 확인하도록 유도하기 위한 안전 장치입니다.
