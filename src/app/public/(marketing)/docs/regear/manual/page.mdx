# 수동 청구

블랙존 외 사망이거나 자동 매칭이 누락된 경우 직접 청구하는 경로입니다. 사망 스크린샷과 자기 사망의 길드·시간·위치를 입력합니다.

## 어떻게 동작하나

`/regear` 에서 "수동 청구" 폼을 열고 다음 정보를 입력합니다.

- 사망 시간·위치 (지역)
- 사망한 캐릭터 / 길드명
- 잃은 장비 (6개 슬롯 각각의 티어 / 인챈트 / 가격)
- 사망 스크린샷 (검증 보조 자료)

제출 후에는 자동 청구와 같은 흐름으로 어드민 승인 큐에 들어갑니다.

## 규칙과 정책

### 부위별 가격 편집을 허용합니다

자동 청구와 마찬가지로, 수동 청구도 시점 시세를 청구자가 직접 입력합니다. 같은 장비라도 인챈트·아티팩트에 따라 가격이 매번 다르고, 시장 호가도 시간대마다 변하기 때문에 청구자가 자기 빌드의 시점 가격을 입력하는 게 가장 정확합니다.
