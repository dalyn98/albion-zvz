# 실버 / 제작 운영 모드

리기어 보상 수단은 청구자가 부위별로 고르는 구조가 아닙니다. 길드 설정의 제작 리기어 토글이 신규 신청의 기본 모드를 정하고, 어드민이 승인 단계에서 실버 지급 / 제작 큐 / 재고 출고 중 하나로 마무리합니다.

## 어떻게 동작하나

1. **토글 OFF** — 신규 리기어는 실버 지급 후보로 생성됩니다.
2. **토글 ON** — 신규 리기어는 제작 후보로 생성됩니다.
3. **어드민 승인** — 제작 후보는 그대로 제작 큐에 보내거나, 이미 보유한 재고로 출고하거나, 실버 지급으로 전환할 수 있습니다.
4. **박스 픽업** — 제작으로 처리된 장비는 길드 제작자가 납품하고, 청구자가 자기 박스 번호를 확인해 회수합니다.


## 규칙과 정책

### 선택 지점을 어드민 승인 단계에 둡니다

청구자가 부위별로 지급 방식을 섞으면 운영 기준이 흐려지고 제작자 큐도 복잡해집니다. 길드는 토글로 기본 정책을 정하고, 실제 지급 방식은 재고·제작자 여유·길드 금고 상황을 아는 어드민이 승인 시점에 결정합니다.
