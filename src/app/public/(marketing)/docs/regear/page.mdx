# 리기어 청구

ZvZ 에서 죽은 길드원이 잃은 장비를 보상받는 흐름입니다. 자동 생성과 수동 청구 두 가지 경로가 있고, 보상 수단은 길드 운영 모드에 따라 실버 또는 제작 후보로 시작합니다. 어드민은 승인 단계에서 실버 지급 / 제작 큐 / 재고 출고 중 하나로 마무리할 수 있습니다. 길드 정책에 따라 오버차지 비용은 사망 횟수와 분리된 특수 수동 청구로 받을 수 있습니다.
