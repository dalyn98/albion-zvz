# 리기어 청구

ZvZ 에서 죽은 길드원이 잃은 장비를 보상받는 흐름입니다. 자동 생성과 수동 청구 두 가지 경로가 있고, 보상 수단은 **실버 / 제작** 듀얼 모드입니다.

## 무엇을 할 수 있나

- ZvZ 후 사망자의 장비를 실버로 보상
- 같은 장비를 길드 제작자가 만들어 박스로 전달
- 자동으로 잡힌 청구를 부위별로 가격 조정해서 제출

## 어떻게 동작하나

### 자동 리기어 (블랙존만)

블랙존 ZvZ 에서 사망이 추적되면 시스템이 자동으로 청구를 만듭니다.

- 처음 상태는 항상 **승인 대기 (pending)** — 청구자가 직접 검토하고 부위별 가격을 편집한 뒤 제출합니다
- 자동 생성 자체는 정기 작업이 돌리며, 어드민이 자동 리기어 토글을 끄면 정기 작업도 멈춥니다
- 청구 화면에서 6개 슬롯 (무기 / 머리 / 갑옷 / 신발 / 보조무기 / 망토) 의 가격을 각각 조정할 수 있습니다

### 수동 청구

블랙존 외 사망이거나 자동 매칭이 누락된 경우 `/regear` 에서 수동으로 청구합니다. 사망 스크린샷과 자기 사망의 길드·시간·위치를 직접 입력합니다.

### 실버 / 제작 듀얼 모드

청구 수단을 두 가지 중 선택합니다.

1. **실버** — 길드 금고에서 실버로 받음 (즉시 정산)
2. **제작** — 청구된 장비를 길드 제작자에게 큐로 전달 → 제작 완료 후 박스로 픽업

같은 청구 안에서 부위별로 다른 모드를 고를 수도 있습니다 (예: 무기는 실버, 갑옷은 제작).

### 검증 흐름

청구가 들어오면 시스템이 알비온 데이터와 매칭합니다.

- 시간 범위 안에 해당 캐릭터의 사망 기록이 있는가
- 사망자의 길드명이 사이트의 홈 길드와 일치하는가
- 매칭되면 자동 통과, 실패하면 "킬보드 미검증" 표시 + 재확인 버튼

검증 실패 시 30분 정도 기다린 후 재시도하면 알비온 쪽 데이터 반영이 끝나 통과되는 경우가 많습니다.

### 어드민 승인

청구가 제출되면 어드민 승인 큐로 들어갑니다. 어드민은 가격 적정성과 이상 정황 (자동 표시되는 anomaly 마크) 을 보고 승인 또는 반려합니다.

## 규칙과 정책

### 자동 리기어도 본인이 한 번 검토합니다

자동 매칭이 곧장 승인까지 처리하면 청구자가 자기 빌드·가격을 통제할 수 없어 "내 빌드는 더 비싼데?", "이 부위는 왜 빠졌나?" 같은 분쟁이 생깁니다. 청구자 본인이 한 번 손대고 제출 → 어드민 승인의 2단계가 신뢰성과 책임의 균형점입니다.

### 자동 리기어는 블랙존만

레드존·옐로우존·블루존 사망은 ZvZ 가 아니라 갱크나 실수가 대부분입니다. 자동 청구가 잘못 잡히는 비용이 너무 커서 블랙존만 자동화하고, 그 외는 멤버가 의식적으로 수동 청구하도록 했습니다.

### 부위별 가격 편집을 허용합니다

같은 T8 갑옷이라도 인챈트·아티팩트가 다르면 시장 가격이 매번 변합니다. 시스템 추정 가격을 그대로 쓰면 청구자가 손해를 보거나 길드가 과지급하는 일이 자주 생기므로 — 청구자가 자기 빌드의 시점 가격을 직접 입력하는 게 가장 정확합니다.

### 실버 + 제작 듀얼 모드

길드 금고가 빠듯하거나 활발한 제작자가 있으면 "실버 대신 만들어 줄게" 가 더 합리적입니다. 두 모드를 한 청구 안에서 선택할 수 있게 해서 부위별로 가장 효율적인 보상 방식을 골라쓸 수 있습니다.

### 길드명 매칭은 띄어쓰기·대소문자 관대

알비온 데이터의 길드명 표기와 사이트 설정의 표기가 띄어쓰기·대소문자만 살짝 다른 경우가 흔합니다 (예: "Another Guild" vs "another guild"). 이런 경우에도 매칭이 되도록 관대하게 비교하지만, 다른 길드와 진짜 충돌은 길드명 자체가 다르므로 안전합니다.
