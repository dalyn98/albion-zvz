# 리기어 청구

ZvZ 에서 죽은 길드원이 잃은 장비를 보상받는 흐름입니다. 자동 생성과 수동 청구 두 가지 경로가 있고, 보상 수단은 실버 / 제작 듀얼 모드입니다. 길드 정책에 따라 오버차지 비용은 사망 횟수와 분리된 특수 수동 청구로 받을 수 있습니다.
