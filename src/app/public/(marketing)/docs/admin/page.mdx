# 어드민 설정

길드 어드민이 사이트의 운영 정책을 조정하는 영역입니다. 토글 / 수치 한 두 개 바꾸면 멤버 화면 전반에 즉시 반영되도록 설계했습니다.

## 사용 시나리오

- 자동 리기어를 잠시 끄거나 다시 켤 때
- 상점 환율 (할인율) 을 조정할 때
- 청구 승인 / 반려를 한 큐에서 처리할 때
- 이벤트, 박스, 길드 금고 잔액 등을 정리할 때

## 사용법

### 어드민 대시보드 (`/admin/dashboard`)

운영자 진입 페이지. 다음 모듈로 분기합니다.

- **승인 큐 (`/admin/dashboard/approvals`)**: 멤버가 제출한 리기어 청구를 가격 / 정황 검증해 승인·반려
- **이벤트 (`/admin/dashboard/events`)**: 정기 ZvZ / 연합전 같은 운영 단위 생성·관리
- **상점 (`/admin/dashboard/shop`)**: 환율 (할인율) 조정, 상품 목록 관리
- **인벤토리 (`/admin/dashboard/inventory`)**: 길드 제작 재고 (장비 단위) 관리
- **리기어 윈도우 (`/admin/dashboard/regear-windows`)**: 자동 리기어 매칭 시간창 / 토글 관리
- **역할 보상 (`/admin/dashboard/role-rewards`)**: 디스코드 역할별 자동 포인트 적립 규칙
- **통계 (`/admin/dashboard/stats`)**: 길드 단위 KPI (청구량, 환율, 출전률 등)
- **운영 가이드 (`/admin/dashboard/guide`)**: 사이트 사용법을 운영자 입장에서 정리한 인앱 매뉴얼

### 글로벌 토글 (app_settings)

자동 리기어 cron, 자동 매칭 윈도우, 알비온 동기화 등 시스템 동작을 제어하는 글로벌 토글이 있습니다. 토글 OFF 면 cron 자체가 돌지 않아 데이터 누적이 즉시 멈춥니다 (AGENTS.md hard rule #5).

### 권한 체계

- **admin**: 사이트 운영자. 승인 큐 / 환율 / 이벤트 등 거의 모든 어드민 기능
- **is_crafter**: 제작 큐 / 인벤토리 관리. 어드민과 별도 권한
- **super-admin**: SaaS 운영자 (사이트 본인). 테넌트 자체 생성 / 정지 등 어드민 위 레이어

## 디자인 결정

### 왜 어드민이 글로벌 토글로 cron 자체를 끌 수 있나

자동 리기어가 의도하지 않은 청구를 양산하기 시작하면 (예: 알비온 API 변경, 잘못된 길드명 매칭) 한 번에 멈출 수단이 필요합니다. 토글을 OFF 로 두면 cron 자체가 돌지 않으므로, 데이터가 더 들어오기 전에 원인 파악 시간을 벌 수 있습니다.

### 왜 어드민 권한과 제작자 (`is_crafter`) 권한이 분리되어 있나

길드 어드민 = 사이트 정책·승인을 다루는 사람, 제작자 = 길드 제작 큐를 처리하는 사람. 두 역할은 보통 다른 사람입니다. 한 권한에 묶으면 제작자에게 청구 승인까지 줘 버리거나, 어드민이 제작 큐를 쥐고 있어야 하는 어색한 상황이 생깁니다 — 분리해서 필요한 만큼만 발급합니다.

### 왜 어드민 화면도 ja/en 다국어가 필수인가

어드민이 한국어 화자가 아닌 길드도 있고, 같은 길드 안에서 보조 어드민이 일본어 / 영어를 쓸 수도 있습니다. 어드민이 보는 화면이라고 해서 한국어 하드코딩을 허용하면 멀티 테넌트 SaaS 가 사실상 한국 길드 전용이 됩니다 (AGENTS.md hard rule #1).

### 왜 어드민 운영 가이드 (`/admin/dashboard/guide`) 가 사이트 안에 있나

이 공식 문서 (`/docs`) 는 도입 전 길드와 멤버를 위한 설명이고, 운영 가이드는 "이미 봇을 설치한 어드민이 매일 쓰는 화면" 을 설명합니다. 두 문서는 독자와 호흡이 달라서, 운영 가이드는 어드민 대시보드 안에서 컨텍스트를 그대로 유지하며 읽을 수 있게 인앱 페이지로 두었습니다.

### 왜 self-serve 봇 초대만으로 모든 기능이 동작해야 하는가

어드민이 별도 SQL 쿼리 / env 토글로 우회해야 동작하는 기능은 사실상 멘헤라 길드 전용 기능입니다. 모든 신기능은 "Discord OAuth 로 봇만 새로 초대한 길드" 가 멘헤라와 동등하게 사용할 수 있어야 합니다 (AGENTS.md hard rule #10) — 어드민 화면도 이 기준을 지킵니다.
