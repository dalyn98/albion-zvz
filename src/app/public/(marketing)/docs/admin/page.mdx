# 어드민 설정

길드 어드민이 사이트의 운영 정책을 조정하는 영역입니다. 토글 / 수치 한두 개 바꾸면 멤버 화면 전반에 즉시 반영되도록 설계했습니다.

## 무엇을 할 수 있나

- 자동 리기어를 잠시 끄거나 다시 켜기
- 상점 환율 (할인율) 조정
- 청구 승인 / 반려를 한 큐에서 처리
- 이벤트, 박스, 길드 금고 잔액 정리

## 어떻게 동작하나

### 어드민 대시보드

`/admin/dashboard` — 운영자 진입 페이지에서 다음 모듈로 분기합니다.

- **승인 큐**: 멤버가 제출한 리기어 청구를 가격 / 정황 검증해 승인·반려
- **이벤트**: 정기 ZvZ / 연합전 같은 운영 단위 생성·관리
- **상점**: 환율 (할인율) 조정, 상품 목록 관리
- **인벤토리**: 길드 제작 재고 (장비 단위) 관리
- **리기어 윈도우**: 자동 리기어 매칭 시간창 / 토글 관리
- **역할 보상**: 디스코드 역할별 자동 포인트 적립 규칙
- **통계**: 길드 단위 요약 지표 (청구량, 환율, 출전률 등)
- **운영 가이드**: 사이트 사용법을 운영자 입장에서 정리한 인앱 매뉴얼

### 글로벌 토글

자동 리기어, 자동 매칭 윈도우, 알비온 동기화 등 시스템 동작을 통째로 제어하는 토글이 있습니다. OFF 로 두면 자동 작업이 즉시 멈춰서, 의도하지 않은 동작이 더 누적되기 전에 원인 파악 시간을 벌 수 있습니다.

### 권한 체계

- **어드민**: 사이트 운영자. 승인 큐 / 환율 / 이벤트 등 거의 모든 어드민 기능을 사용
- **제작자**: 길드 제작 큐 / 인벤토리 관리. 어드민과 별도 권한
- **사이트 운영자**: SaaS 자체를 운영하는 입장. 길드 단위의 생성 / 정지 같은 어드민 위 레이어

## 규칙과 정책

### 자동 작업은 글로벌 토글로 통째로 끌 수 있습니다

자동 리기어가 의도하지 않은 청구를 양산하기 시작하면 (예: 알비온 데이터 변경, 잘못된 길드명 매칭) 한 번에 멈출 수단이 필요합니다. 토글을 OFF 로 두면 자동 작업이 아예 돌지 않으므로, 데이터가 더 들어오기 전에 원인 파악 시간을 확보할 수 있습니다.

### 어드민과 제작자 권한은 별개

길드 어드민 = 사이트 정책·승인을 다루는 사람, 제작자 = 길드 제작 큐를 처리하는 사람. 두 역할은 보통 다른 사람입니다. 한 권한에 묶으면 제작자에게 청구 승인까지 줘 버리거나, 어드민이 제작 큐를 쥐고 있어야 하는 어색한 상황이 생깁니다 — 분리해서 필요한 만큼만 발급합니다.

### 어드민 화면도 한국어 / 일본어 / 영어 모두 지원

어드민이 한국어 화자가 아닌 길드도 있고, 같은 길드 안에서 보조 어드민이 일본어 / 영어를 쓸 수도 있습니다. "어드민이 보는 화면이라" 한국어만 두면 사이트가 사실상 한국 길드 전용이 됩니다.

### 운영 가이드는 어드민 화면 안에 있습니다

이 공식 문서는 도입 전 길드와 멤버를 위한 설명이고, 운영 가이드는 "이미 봇을 설치한 어드민이 매일 쓰는 화면" 을 설명합니다. 두 문서는 독자와 호흡이 달라서, 운영 가이드는 어드민 화면 안에 인앱으로 두어 컨텍스트를 그대로 유지하며 읽을 수 있게 했습니다.

### 봇만 새로 초대해도 모든 기능이 동작합니다

어드민이 별도 데이터베이스 작업이나 환경 변수를 손대야 동작하는 기능이 있으면 사실상 일부 길드 전용입니다. 모든 신기능은 디스코드 OAuth 로 봇만 새로 초대한 길드에서도 기존 길드와 동등하게 작동하는 것을 기준으로 설계합니다.
