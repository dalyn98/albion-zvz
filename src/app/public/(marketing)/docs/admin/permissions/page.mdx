# 권한 체계

길드 운영의 역할을 어드민 / 제작자 / 사이트 운영자로 분리하고, 각 역할이 접근하는 화면을 분리합니다.

## 어떻게 동작하나

- **어드민**: 사이트 운영자. 승인 큐 / 환율 / 이벤트 등 거의 모든 어드민 기능을 사용
- **제작자**: 길드 제작 큐 / 인벤토리 관리. 어드민과 별도 권한
- **로그 운영 담당**: 길드 상자 로그, 사이펀 장부, 루팅 검증처럼 인게임 로그를 다루는 기능만 위임
- **사이트 운영자**: SaaS 자체를 운영하는 입장. 길드 단위의 생성 / 정지 같은 어드민 위 레이어

권한 화면의 역할 프리셋은 실제 업무 기준으로 묶여 있습니다. 상점 보급관은 상점·재고·상자 로그 권한을 함께 받고, 로그 운영 담당은 상자 로그 붙여넣기, 사이펀 관리, 감사 로그 확인 권한을 받습니다. 프리셋 적용 후에도 세부 권한은 직접 추가하거나 뺄 수 있습니다.


## 규칙과 정책

### 어드민과 제작자 권한은 별개

길드 어드민 = 사이트 정책·승인을 다루는 사람, 제작자 = 길드 제작 큐를 처리하는 사람. 두 역할은 보통 다른 사람입니다. 한 권한에 묶으면 제작자에게 청구 승인까지 줘 버리거나, 어드민이 제작 큐를 쥐고 있어야 하는 어색한 상황이 생깁니다 — 분리해서 필요한 만큼만 발급합니다.
