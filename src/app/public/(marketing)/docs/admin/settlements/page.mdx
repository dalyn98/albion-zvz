# 월말 정산

`/admin/dashboard/settlements` — 길드 포인트 원장을 월 단위로 고정해 개인별 지급 / 납부 금액을 확인하는 화면입니다.

## 어떻게 동작하나

- 정산 월을 선택하면 해당 월 시작 전 잔액, 월중 지급, 월중 사용, 월말 잔액을 계산합니다
- 정산 라인은 생성 시점에 스냅샷으로 저장되므로 이후 포인트 변동이 과거 정산을 바꾸지 않습니다
- 관리자 화면에서 CSV 를 내려받아 엑셀 / 구글시트로 확인할 수 있습니다
- 멤버는 `/me/settlements` 에서 자기 정산 라인만 확인합니다
- 마감 처리하면 운영자가 해당 정산을 더 이상 임시 검토 상태로 보지 않게 됩니다

## 숫자 의미

- **시작 잔액**: 정산 월이 시작되기 전까지 쌓인 누적 잔액
- **지급**: 정산 월 안에 멤버에게 적립된 포인트
- **사용**: 정산 월 안에 환전 / 상점 구매 / 양도 송신 등으로 빠진 포인트
- **월말 잔액**: 시작 잔액 + 지급 - 사용
- **지급 예정**: 월말 잔액이 양수일 때 길드가 멤버에게 지급할 금액
- **납부 예정**: 월말 잔액이 음수일 때 멤버가 길드에 정리할 금액

## 권한

전체 어드민은 항상 접근할 수 있습니다. 비어드민 담당관에게 맡기려면 권한 관리에서 `월말 정산 관리` capability 를 부여합니다.

## 운영 팁

정산을 만들기 전에는 승인 대기 중인 리기어 / 환전 / 상점 주문을 먼저 정리하는 편이 좋습니다. 대기 중인 요청은 아직 포인트 원장에 반영되지 않았을 수 있으므로, 월말 잔액과 실제 지급 예정 금액이 어긋나 보일 수 있습니다.
