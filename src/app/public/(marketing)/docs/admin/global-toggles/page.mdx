# 글로벌 토글

자동 리기어, 자동 매칭 윈도우, 알비온 동기화 등 시스템 동작을 통째로 제어하는 토글입니다. OFF 로 두면 자동 작업이 즉시 멈춥니다.

## 어떻게 동작하나

각 자동 작업은 글로벌 토글로 ON / OFF 상태를 가집니다. 어드민이 화면에서 한 번 클릭하면 그 시점부터 해당 작업이 멈추고, 다시 ON 으로 두면 정상 주기로 재개됩니다.

## 규칙과 정책

### 자동 작업은 글로벌 토글로 통째로 끌 수 있습니다

자동 리기어가 의도하지 않은 청구를 양산하기 시작하면 (예: 알비온 데이터 변경, 잘못된 길드명 매칭) 한 번에 멈출 수단이 필요합니다. 토글을 OFF 로 두면 자동 작업이 아예 돌지 않으므로, 데이터가 더 들어오기 전에 원인 파악 시간을 확보할 수 있습니다.
