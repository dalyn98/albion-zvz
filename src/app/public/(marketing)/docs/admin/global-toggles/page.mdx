# 글로벌 토글

자동 리기어, 자동 매칭 윈도우, 알비온 동기화 등 시스템 동작을 통째로 제어하는 토글입니다. OFF 로 두면 자동 작업이 즉시 멈춥니다.

## 어떻게 동작하나

각 자동 작업은 글로벌 토글로 ON / OFF 상태를 가집니다. 어드민이 화면에서 한 번 클릭하면 그 시점부터 해당 작업이 멈추고, 다시 ON 으로 두면 정상 주기로 재개됩니다.


## 규칙과 정책

### 자동 작업은 글로벌 토글로 통째로 끌 수 있습니다

자동 리기어가 의도하지 않은 청구를 양산하기 시작하면 (예: 알비온 데이터 변경, 잘못된 길드명 매칭) 한 번에 멈출 수단이 필요합니다. 토글을 OFF 로 두면 자동 작업이 아예 돌지 않으므로, 데이터가 더 들어오기 전에 원인 파악 시간을 확보할 수 있습니다.

## 주요 토글 목록

### 리기어 · 보상

- **자동 리기어 (auto_regear_enabled)** — 블랙존 사망을 5분 주기로 스캔해 청구를 자동 생성합니다. OFF 면 정기 작업이 아예 돌지 않습니다
- **제작 리기어 (craft_regear_enabled)** — 청구자가 부위별로 "실버 보상" / "제작 의뢰" 중 하나를 고를 수 있게 합니다. OFF 면 실버 모드 단일
- **자동 청구 제외 슬롯 (auto_regear_excluded_slots)** — 음식 · 망토 · 탈것 · 포션 등 자동 청구에서 빼고 싶은 슬롯을 어드민이 직접 선택합니다 (기본값: 음식 · 망토 · 탈것 · 포션)
- **신뢰도 낮은 슬롯 자동 제외 (auto_regear_skip_low_confidence)** — AODP 시세 표본이 빈약한 슬롯을 청구에 포함하지 않고 청구자가 직접 추가하도록 유도합니다

### 시세 산정 (AODP)

- **기준 도시 + 폴백 풀 (aodp_cities)** — 시세 추정에 쓸 로열 도시 목록. 1순위 도시에 데이터가 없으면 나머지를 가중 중앙값으로 폴백합니다
- **품질 축 제거 (aodp_quality_agnostic)** — 같은 (uniqueName, 인챈트) 면 모든 품질을 같은 단가로 처리합니다 (인벤토리 행은 품질별 보존)
- **최소 품질 / 가격 모드 (aodp_min_quality, aodp_price_mode)** — 시세 후보군에 포함할 거래의 품질 하한과 산정 방식 (예: 가중 중앙값 / 최저가)

### 이벤트

- **이벤트 자동 시작 (events_auto_start_enabled)** — 모집 시간이 지나면 이벤트를 자동으로 "진행 중" 으로 전환합니다
- **이벤트 DM 안내 (event_dm_lead_minutes)** — 모임 시각 N 분 전 참가자에게 디스코드 DM 발송
- **참가예정 모드** — 슬롯이 정해지기 전 멤버가 가능 역할군을 미리 표시할 수 있는 흐름 (이벤트별 ON / OFF)
- **솔로 폭딜러 슬롯** — 1명짜리 솔로 폭딜 슬롯을 별도로 표시해 일반 슬롯과 분리 운영

### 통계 · 동기화

- **킬보드 동기화 (last_killboard_sync_at)** — 알비온 공식 API 5분 주기 자동 갱신. 데이터 이상 시 임시 OFF 가능
- **전투 추적 (last_battle_tracker_sync_at)** — `/battles` 엔드포인트 기반 ZvZ 한 판 단위 집계
- **번들 분리 집계 (bundle_split_battles_in_stats)** — 한 전투의 다중 알라이언스를 상대별로 분리해 통계에 잡습니다

### 길드 공개 페이지

- **길드 공개 프로필 (guild_profile_enabled)** — `/g/<slug>` 길드 공개 페이지를 켜고 끕니다
- **공개 항목 토글 (guild_profile_show_*)** — 멤버 수 / 전투 기록 / 리기어 통계 / 리더보드 / 어드민 명단 등 공개 페이지에 노출할 섹션을 항목별로 선택

> 토글 키 이름은 어드민 → 사용법 가이드 (인앱) 또는 사이트 설정 화면에서 친화 라벨로 확인할 수 있습니다.
