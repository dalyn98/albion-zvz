# 운영 가이드 (인앱)

`/admin/dashboard/guide` — 사이트 사용법을 운영자 입장에서 정리한 인앱 매뉴얼입니다. 이 공식 문서와는 독자가 다릅니다.

## 어떻게 동작하나

어드민 대시보드 안에서 가이드 페이지를 직접 열어, 매일 쓰는 화면 순서대로 운영 팁과 단축키를 봅니다. 다른 어드민 화면과 같은 컨텍스트에서 읽을 수 있어 작업 흐름이 끊기지 않습니다.

## 규칙과 정책

### 공식 문서와 운영 가이드는 다른 독자

이 공식 문서는 도입 전 길드와 멤버를 위한 설명이고, 운영 가이드는 "이미 봇을 설치한 어드민이 매일 쓰는 화면" 을 설명합니다. 두 문서는 독자와 호흡이 달라서, 운영 가이드는 어드민 화면 안에 인앱으로 두어 컨텍스트를 그대로 유지하며 읽을 수 있게 했습니다.
