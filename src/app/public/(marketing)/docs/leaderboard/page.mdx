# 업적 · 통계 · 리더보드

길드원의 ZvZ 활동을 정량적으로 비교·격려하는 영역입니다. 업적 (badge), 무기 사용 패턴, 길드 안 순위 (leaderboard) 가 같은 데이터에서 파생됩니다.

## 사용 시나리오

- 길드원이 자기 ZvZ 기여를 시각적으로 확인하고 싶을 때
- 어드민이 "이번 달 출전 / 생존 / 킬" 우수자에게 보상을 줄 때
- 빌드 트렌드를 보고 길드 메타를 조정할 때

## 사용법

### 멤버 상세의 업적 (`/members/[discordId]`)

각 길드원 카드에서 업적 그리드 (BadgeGrid) 가 노출됩니다. 진행도 / 달성 시점이 같이 표시되고, 업적 카드를 누르면 산정 근거 (어떤 전투들이 카운트됐는지) 를 볼 수 있습니다.

### 무기 사용 통계 (멤버 상세)

같은 장비라도 티어 / 인챈트 / 품질 / 아티팩트가 매번 다른데, 통계는 이걸 카테고리로 통합해 표시합니다.

- 이름 표기는 T8 canonical id 기준 ("장로의 스피릿헌터" 같은 통일 표기)
- 카운트 단위는 **1 전투당 1** — 한 전투에서 킬/데스가 10번 떠도 그 전투는 1로만 셈
- 킬 로그 자체는 원본 Type 문자열을 보존해 정확히 어떤 인챈트로 잡았는지 확인 가능

### 리더보드 (`/leaderboard`)

길드 내 순위 화면. 업적·통계와 같은 필터를 통과한 데이터로 집계됩니다.

## 디자인 결정

### 왜 업적/통계 킬 집계가 `/battles` 판정 규칙을 따르는가

업적이 "1대1 갱킹 누적" 으로 채워지면 ZvZ 의미가 사라집니다. 그래서 **전투 페이지에서 ZvZ 로 인정된 전투의 킬만** 업적·통계에 들어갑니다 — 10명 미만 갱크 자동 제외, low-engagement 컷, 어드민이 enable 한 size category, 홈/상대 얼라이언스 매칭 통과의 4 단 필터 (AGENTS.md hard rule #8).

### 왜 생존률 업적은 DPS 를 제외하나

DPS 는 최전방 딜러 특성상 사망률이 구조적으로 높습니다. "유령 / 불사의 징조" 같은 생존률 업적을 그대로 적용하면 DPS 는 영원히 못 받는 업적이 됩니다. 그래서 생존률 업적의 평가 모수에서 DPS 역할 참여는 제외하고, 카드에 툴팁으로 그 사실을 노출합니다.

### 왜 무기 통계는 카테고리로 통합하나

같은 양손도끼라도 T7 / T8 / 인챈트 / 아티팩트가 itemId 가 다릅니다. 이걸 다 따로 세면 "양손도끼 사용 빈도" 같은 의미 있는 숫자가 안 나옵니다. `extractWeaponCategory` 로 family code 까지 좁히고, 표기는 T8 canonical 로 정규화해 한 줄로 보여줍니다 (AGENTS.md hard rule #7).

### 왜 통계 카운트는 row 가 아니라 1 전투당 1 인가

한 ZvZ 한 판에서 킬 이벤트가 10개 쌓여도 그 사람이 그 전투에서 그 무기를 "썼다" 는 사실은 1번입니다. row 수로 세면 격렬한 전투 한 번에 10배 가중되어 무기 트렌드가 왜곡됩니다 — `findTrackedBattleKey()` 로 전투 키 단위로 묶고 `Set<battleKey>.size` 로 카운트합니다.
