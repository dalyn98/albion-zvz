# 업적

각 길드원 카드에서 업적 그리드가 노출됩니다. 진행도와 달성 시점이 같이 표시되고, 업적을 누르면 산정 근거 (어떤 전투들이 카운트됐는지) 를 볼 수 있습니다.

## 어떻게 동작하나

- 멤버 상세 페이지에서 업적 그리드 표시
- 진행도 / 달성 시점 / 카운트 근거를 카드 단위로
- 업적 카드를 펼치면 어떤 전투들이 산정에 들어갔는지 보임

## 규칙과 정책

### 업적·통계 킬 집계는 ZvZ 로 인정된 전투만

업적이 "1대1 갱킹 누적" 으로 채워지면 ZvZ 의 의미가 사라집니다. 그래서 **전투 페이지에서 ZvZ 로 인정된 전투의 킬만** 업적·통계에 들어갑니다 — 10명 미만 갱크 자동 제외, 한쪽이 거의 안 싸운 전투 컷, 어드민이 켠 규모 카테고리, 우리 길드 vs 상대 매칭 통과의 4 단 필터입니다.

### 생존률 업적은 DPS 를 모수에서 뺍니다

DPS 는 최전방 딜러 특성상 사망률이 구조적으로 높습니다. "유령 / 불사의 징조" 같은 생존률 업적을 그대로 적용하면 DPS 는 영원히 못 받는 업적이 됩니다. 그래서 생존률 업적의 평가 모수에서 DPS 역할 참여는 제외하고, 카드 툴팁에 그 사실을 노출합니다.
