# 리더보드

`/leaderboard` 에서 길드 안 순위를 봅니다. 업적·통계와 같은 필터를 통과한 데이터로 집계됩니다.

## 어떻게 동작하나

- 출전 / 생존 / 킬 / 명성 같은 카테고리별 순위
- 시즌·기간 필터로 "이번 달", "최근 7일" 등 단위로 비교
- 멤버 카드 클릭 → 멤버 상세 페이지로 이동


## 규칙과 정책

### 같은 데이터에서 같은 규칙으로 산정

리더보드 / 업적 / 통계는 같은 데이터에서 같은 필터로 만들어집니다. 어느 화면에서 본 숫자가 다른 화면에서 다르게 보이지 않도록, "이 사람의 ZvZ 킬 5번" 은 어느 화면에서나 같은 5번이어야 합니다. 한 가지 산정 규칙으로 모든 순위·업적이 일관되게 나오도록 했습니다.
