# 박스 픽업 (청구자)

제작 모드 청구의 마지막 단계입니다. 박스 번호와 도시가 청구 화면에 노출되면, 청구자가 게임 안에서 박스에서 장비를 꺼냅니다.

## 어떻게 동작하나

청구자의 청구 상세 화면에 박스 번호와 도시가 표시됩니다. 청구자는 게임 안에서 박스를 열어 장비를 꺼내고, 사이트에서 **"수거 확인"** 을 누르면 청구가 종료됩니다.

## 규칙과 정책

### 수거 확인은 청구 종료용

수거 확인을 눌러도 길드 재고는 더 이상 변하지 않습니다 (박스 납품 시점에 이미 차감됨). 수거 확인 자체는 "이 청구는 끝났다" 는 표시 — 청구자 본인의 작업이 완료됐음을 사이트에 명시하는 용도입니다.
