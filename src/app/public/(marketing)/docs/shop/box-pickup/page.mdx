# 박스 픽업

상점에서 구매한 장비는 길드 금고 박스에서 직접 받습니다. 게임 안에서 직접 양도가 어려운 알비온의 특성을 고려한 흐름입니다.

## 어떻게 동작하나

구매 후 안내 메시지에 박스 위치 / 도시 정보가 노출됩니다. 멤버는 게임 안에서 해당 박스에 접근해 장비를 꺼내고, 사이트에서는 별도의 수거 확인 액션 없이 구매가 완료된 것으로 처리됩니다.

## 규칙과 정책

### 알비온은 직접 양도가 제한적입니다

알비온은 게임 안에서 직접 아이템을 양도할 방법이 제한적입니다. 어드민이 "X 캐릭터에게 보낸다" 라고 약속한 박스 (Bank chest) 에 장비를 두고 멤버가 픽업하는 흐름이 자연스러워서, 사이트는 그 흐름을 그대로 표현합니다.
