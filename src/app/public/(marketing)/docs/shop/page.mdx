# 길드 상점

길드원이 모은 포인트로 길드 금고의 장비/소모품을 살 수 있는 상점입니다. 핵심은 **포인트 ↔ 실버** 환율 (= 할인율) 한 가지로 가격 정책을 조절합니다.

## 사용 시나리오

- ZvZ 참여·제작 기여로 받은 포인트를 실제 장비로 교환할 때
- 길드 금고에 있는 잉여 장비를 멤버에게 분배할 때
- 어드민이 "이번 달은 50% 할인" 같은 이벤트성 가격 조정을 할 때

## 사용법

### 상점 화면 (`/shop`)

- 상품 카드: 아이콘 / 이름 / 적용된 환율의 가격 (포인트)
- 구매 버튼 → 즉시 차감 + 길드 금고에서 박스로 이전 안내

### 환율 조정 (어드민)

전역 환율 1개 — 100% 면 실버 가격 그대로 포인트 가격, 50% 면 절반 가격으로 판매.

```
포인트 가격 = 실버 시세 × (환율 / 100)
```

### 포인트 적립

포인트는 ZvZ 참여·제작·기여 등 시스템이 정의한 활동에 따라 적립됩니다. 청구 승인 시 음수로 차감되는 흐름은 별개 (= 리기어 청구).

## 디자인 결정

### 왜 환율과 할인율이 같은 값인가

"환율" 과 "할인율" 은 같은 숫자를 두 가지 관점으로 부르는 이름입니다 (AGENTS.md hard rule #6). 100% = 시세 1:1 = 할인 없음, 50% = 시세 절반에 판매 = 50% 할인. UI 카피는 "할인율" 이지만 내부에서는 환율 (포인트당 실버) 로 계산해서, 가격 변경 한 번에 모든 상품이 일관되게 갱신됩니다.

### 왜 환율을 전역 1개로 두는가

상품마다 환율을 따로 두면 가격표가 너무 복잡해지고, 시즌별 이벤트 ("이번 주 50% 할인") 같은 운영을 못 합니다. 전역 1개로 두고 모든 상품에 곱하는 방식이 "리기어 청구를 자주 했더니 금고가 빈다 → 포인트 환율을 30% 로 낮춰 회전을 늦춘다" 같은 운영 의도를 가장 직관적으로 반영합니다.

### 왜 1:1 (포인트 = 실버) 가 기본인가

포인트와 실버 가격을 멤버가 머릿속에서 환산하지 않게 하려는 의도입니다. 환율 100% 일 때 5M 실버 짜리 장비는 5M 포인트 — 실버 시세를 그대로 인식하면 됩니다. 할인을 줄 때만 환율을 손대게 해서 평소 의사결정이 단순합니다.

### 왜 박스 픽업 안내가 있는가

알비온은 게임 안에서 직접 아이템을 양도할 방법이 제한적입니다. 어드민이 "X 캐릭터에게 보낸다" 라고 약속한 박스 (Bank chest) 에 장비를 두고 멤버가 픽업하는 흐름이 자연스러워서, 구매 후 안내 메시지가 박스 위치를 노출합니다.
