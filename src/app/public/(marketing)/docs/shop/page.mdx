# 길드 상점

길드원이 모은 포인트로 길드 금고의 장비·소모품을 살 수 있는 상점입니다. 가격 정책은 **포인트와 실버 사이의 환율** 한 가지로 조절합니다 (= 할인율).

## 무엇을 할 수 있나

- ZvZ 참여·제작 기여로 받은 포인트를 실제 장비로 교환
- 길드 금고에 있는 잉여 장비를 멤버에게 분배
- "이번 달은 50% 할인" 같은 이벤트성 가격 조정 (어드민)

## 어떻게 동작하나

### 상점 화면

`/shop` 에서 상품 카드를 봅니다.

- 아이콘 / 이름 / 적용된 환율의 가격 (포인트)
- 구매 버튼을 누르면 즉시 포인트 차감 + 길드 금고 박스에서 픽업하라는 안내가 표시됩니다

### 환율 조정 (어드민)

전역 환율 한 개로 전체 상품 가격을 조절합니다 — 100% 면 실버 가격 그대로 포인트 가격, 50% 면 절반 가격에 판매.

```
포인트 가격 = 실버 시세 × (환율 / 100)
```

### 포인트 적립

포인트는 ZvZ 참여·제작·기여 등 사이트가 정의한 활동에 따라 적립됩니다. 청구 승인 시 음수로 차감되는 흐름은 별개입니다 (= 리기어 청구).

## 규칙과 정책

### 환율과 할인율은 같은 값입니다

"환율" 과 "할인율" 은 같은 숫자를 두 가지 관점으로 부르는 이름입니다. 100% = 시세 1:1 = 할인 없음, 50% = 시세 절반에 판매 = 50% 할인. 화면에서는 "할인율" 이라고 표시하지만 내부에서는 환율 한 개로 계산해서, 가격 변경 한 번에 모든 상품이 일관되게 갱신됩니다.

### 환율은 전역 한 개

상품마다 환율을 따로 두면 가격표가 너무 복잡해지고, "이번 주 50% 할인" 같은 시즌 이벤트 운영을 못 합니다. 전역 한 개로 두고 모든 상품에 곱하는 방식이 "리기어 청구를 자주 했더니 금고가 빈다 → 환율을 30% 로 낮춰 회전을 늦춘다" 같은 운영 의도를 가장 직관적으로 반영합니다.

### 1:1 (포인트 = 실버) 이 기본

포인트와 실버 가격을 멤버가 머릿속에서 환산하지 않게 하려는 의도입니다. 환율 100% 일 때 5M 실버짜리 장비는 5M 포인트 — 실버 시세를 그대로 인식하면 됩니다. 할인을 줄 때만 환율을 손대게 해서 평소 의사결정이 단순합니다.

### 박스 픽업 안내

알비온은 게임 안에서 직접 아이템을 양도할 방법이 제한적입니다. 어드민이 "X 캐릭터에게 보낸다" 라고 약속한 박스 (Bank chest) 에 장비를 두고 멤버가 픽업하는 흐름이 자연스러워서, 구매 후 안내 메시지가 박스 위치를 노출합니다.
