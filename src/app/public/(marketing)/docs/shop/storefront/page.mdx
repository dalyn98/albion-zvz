# 상점 화면

`/shop` 에서 상품 카드를 봅니다. 길드원이 모은 포인트로 결제하고 박스 픽업 안내를 받습니다.

## 어떻게 동작하나

- 아이콘 / 이름 / 적용된 환율의 가격 (포인트)
- 구매 버튼을 누르면 즉시 포인트 차감 + 길드 금고 박스에서 픽업하라는 안내가 표시됩니다


## 규칙과 정책

### 1:1 (포인트 = 실버) 이 기본

포인트와 실버 가격을 멤버가 머릿속에서 환산하지 않게 하려는 의도입니다. 환율 100% 일 때 5M 실버짜리 장비는 5M 포인트 — 실버 시세를 그대로 인식하면 됩니다. 할인을 줄 때만 환율을 손대게 해서 평소 의사결정이 단순합니다.
