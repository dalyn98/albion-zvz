# 포인트 적립

포인트는 ZvZ 참여·제작·기여 등 사이트가 정의한 활동에 따라 적립됩니다. 멤버는 포인트로 길드 상점에서 장비를 구매할 수 있습니다.

## 어떻게 동작하나

- ZvZ 참여 / 출석 → 정해진 적립 규칙에 따라 자동 가산
- 길드 제작 기여 → 어드민이 정한 단가로 가산
- 어드민이 직접 가감 (특별 보상, 보정 등)

청구 승인 시 음수로 차감되는 흐름은 별개입니다 (= 리기어 청구).

## 규칙과 정책

### 적립 규칙은 어드민 설정에서 정의

길드마다 "이번 시즌은 ZvZ 출석 가중치를 높인다" 같은 정책이 다릅니다. 그래서 적립 규칙은 어드민이 화면에서 직접 정의하고, 멤버는 자기 적립 내역을 시간순으로 확인하는 구조로 두었습니다.
