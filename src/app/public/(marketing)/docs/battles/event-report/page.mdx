# 이벤트 보고서

이벤트는 사이트가 정의한 운영 단위입니다 (정기 ZvZ, 연합전 등). 한 이벤트가 여러 전투를 포함할 수 있고, 보고서는 그 합계를 보여줍니다.

## 어떻게 동작하나

`/events/[이벤트ID]/report` 에서 이벤트 한 차수의 결과를 종합해 봅니다.

- 포함된 전투들의 K-D 합계
- 참가자별 출전 / 사망 통계
- 자동 생성된 청구 합계와 보상 비용

## 규칙과 정책

### 이벤트가 전투 위에 따로 있습니다

ZvZ 한 판은 알비온 데이터의 단위지만, 길드 운영자가 보는 단위는 보통 "이날 정기전" 처럼 묶인 여러 전투의 모음입니다. 이벤트를 한 단계 위에 두면 청구·통계를 한 운영 차수 단위로 정리할 수 있습니다.
