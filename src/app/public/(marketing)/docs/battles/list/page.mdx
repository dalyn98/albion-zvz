# 전투 목록

`/battles` 에서 알비온의 전투 데이터를 사이트의 집계 규칙에 맞춰 필터링한 결과를 카드로 보여줍니다. 클릭하면 상세로 들어갑니다.

## 어떻게 동작하나

알비온이 제공하는 모든 전투 중 "10명 이상", "양쪽 모두 실제로 싸운" 전투만 골라서 노출합니다. 카드에는 시간 / 참가자 수 / 길드별 결과가 요약돼 있고, 클릭하면 전투 상세로 이동합니다.


## 규칙과 정책

### 10명 미만 전투는 자동으로 빠집니다

길드원 1~2명이 갱크당한 작은 사건까지 전투 통계에 들어가면 평균값이 무너지고, 자동 리기어가 적합하지 않은 케이스가 청구로 끌려옵니다. 그래서 **10명 미만은 갱크로 분류해 집계에서 자동 제외** 합니다. 이 규칙은 통계와 업적 킬 집계에도 똑같이 적용됩니다.

### 한쪽이 거의 안 싸운 전투도 빠집니다

10명을 넘어도 한 쪽이 빠르게 도주해서 끝난 전투는 ZvZ 의 의미가 약합니다. 양쪽의 실제 교전 강도를 보고 그런 전투는 추가로 잘라냅니다 — "10인 이상" 만으로는 부족한 부분을 메우는 2차 필터입니다.

### 3-way 전투는 상대별로 분리합니다

A vs B vs C 같은 3자 전투는 알비온이 하나의 전투로 줍니다. 사이트는 이걸 "우리 길드 vs 상대 연합" 단위로 분리해서 표시·집계합니다 — 그래야 "우리 vs B 의 K/D" 같은 정확한 숫자가 나옵니다.
