# 전투 집계 & 이벤트 보고서

여러 명의 킬·데스를 시간·위치·참가자로 묶어 "ZvZ 한 판" 으로 정리하고, 길드 단위 결과 보고서로 모으는 영역입니다.

## 무엇을 할 수 있나

- ZvZ 후 "이번 판은 몇 명이 어떻게 싸웠나" 를 한눈에 확인
- 사망자 자동 청구가 어떤 전투에 매칭됐는지 확인
- 파티별·연합별 결과 분리해서 보기
- 정기 ZvZ 한 차수 (이벤트) 단위로 결과 묶음

## 어떻게 동작하나

### 전투 목록

`/battles` 에서 알비온의 전투 데이터를 사이트의 집계 규칙에 맞춰 필터링한 결과를 카드로 보여줍니다. 클릭하면 상세로 들어갑니다.

### 전투 상세

`/battles/[전투ID]` 에서는 한 판의 종합 정보를 봅니다.

- 참가자 명단 (길드별·연합별 그룹)
- 킬·데스 요약과 명성·실버 합계
- 각 참가자 카드를 펼치면 그 사람의 킬·데스 로그
- 이 전투에서 자동 생성된 리기어 청구 링크

### 이벤트 보고서

`/events/[이벤트ID]/report` — 이벤트는 사이트가 정의한 운영 단위입니다 (정기 ZvZ, 연합전 등). 한 이벤트가 여러 전투를 포함할 수 있고, 보고서는 그 합계를 보여줍니다.

### 파티별 보기

`/events/[이벤트ID]/party/[파티번호]` — 이벤트 안에서 사람들을 파티로 묶어 분류한 화면입니다. 콜이나 빌드별 결과를 따로 보고 싶을 때 사용합니다.

## 규칙과 정책

### 10명 미만 전투는 자동으로 빠집니다

길드원 1~2명이 갱크당한 작은 사건까지 전투 통계에 들어가면 평균값이 무너지고, 자동 리기어가 적합하지 않은 케이스가 청구로 끌려옵니다. 그래서 **10명 미만은 갱크로 분류해 집계에서 자동 제외** 합니다. 이 규칙은 통계와 업적 킬 집계에도 똑같이 적용됩니다.

### 한쪽이 거의 안 싸운 전투도 빠집니다

10명을 넘어도 한 쪽이 빠르게 도주해서 끝난 전투는 ZvZ 의 의미가 약합니다. 양쪽의 실제 교전 강도를 보고 그런 전투는 추가로 잘라냅니다 — "10인 이상" 만으로는 부족한 부분을 메우는 2차 필터입니다.

### 3-way 전투는 상대별로 분리합니다

A vs B vs C 같은 3자 전투는 알비온이 하나의 전투로 줍니다. 사이트는 이걸 "우리 길드 vs 상대 연합" 단위로 분리해서 표시·집계합니다 — 그래야 "우리 vs B 의 K/D" 같은 정확한 숫자가 나옵니다.

### 이벤트가 전투 위에 따로 있습니다

ZvZ 한 판은 알비온 데이터의 단위지만, 길드 운영자가 보는 단위는 보통 "이날 정기전" 처럼 묶인 여러 전투의 모음입니다. 이벤트를 한 단계 위에 두면 청구·통계를 한 운영 차수 단위로 정리할 수 있습니다.
