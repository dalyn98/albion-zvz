# 전투 상세

`/battles/[전투ID]` 에서는 한 판의 종합 정보를 봅니다. 참가자 / K-D / 명성 / 자동 청구 매칭이 한 화면에 모입니다.

## 어떻게 동작하나

- 참가자 명단 (길드별·연합별 그룹)
- 킬·데스 요약과 명성·실버 합계
- 각 참가자 카드를 펼치면 그 사람의 킬·데스 로그
- 이 전투에서 자동 생성된 리기어 청구 링크

## 규칙과 정책

### 참가자 카드 → 펼침 구조

한 전투에 30~50명이 참여하면 킬·데스 로그가 수백 개 쌓입니다. 한 화면에 다 쏟아내면 누가 어떻게 싸웠는지 못 읽습니다. 참가자 카드 단위로 K/D 를 요약해 보여주고, 더 보고 싶은 사람만 펼치는 식이 가장 읽기 편합니다.
