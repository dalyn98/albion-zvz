# 전투 상세에서 보기

ZvZ 한 판 단위로 묶인 화면에서 그 전투에 참여한 사람들의 킬·데스 로그를 봅니다. 한 번에 너무 많은 데이터가 쏟아지지 않도록 카드 → 클릭 → 펼쳐지는 구조입니다.

## 어떻게 동작하나

`/battles/[전투ID]` 에서 한 판의 종합 정보를 봅니다.

- 참가자 카드: 길드별·연합별 그룹
- 카드 클릭 → 그 사람의 킬·데스 로그 상세 펼침
- 이 전투에서 자동 생성된 리기어 청구 링크가 같이 노출


## 규칙과 정책

### 카드 → 펼침 구조

한 ZvZ 에 30~50명이 참여하면 킬·데스 로그가 수백 개 쌓입니다. 한 화면에 다 쏟아내면 누가 어떻게 싸웠는지 못 읽습니다. 참가자 카드 단위로 K/D 를 요약해 보여주고, 더 보고 싶은 사람만 펼치는 식이 가장 읽기 편합니다.
