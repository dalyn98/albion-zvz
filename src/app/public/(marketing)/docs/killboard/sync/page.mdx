# 자동 동기화

별도 조작 없이 시스템이 정기적으로 알비온 데이터를 가져와 사이트에 누적합니다. 사용자는 사이트에 들어와 결과만 확인하면 됩니다.

## 어떻게 동작하나

알비온 공식 데이터를 일정 주기로 호출해 길드원의 킬·데스를 사이트 데이터베이스에 저장합니다. 자동 리기어 매칭, 통계 집계, 업적 진행도 갱신이 모두 이 데이터에서 파생됩니다.

## 규칙과 정책

### 사이트가 자체적으로 데이터를 보관합니다

알비온 공식 데이터는 30분 정도 반영 지연이 있고, 과거 데이터 검색에도 제약이 있습니다. 모든 화면이 매번 알비온 쪽을 호출하면 느리고 불안정해지므로, 사이트가 자체 저장소에 누적해서 안정성을 확보합니다.

### 알비온의 30분 반영 지연은 그대로 보입니다

청구 시 알비온 데이터로 사망 사실을 확인하는데, 너무 최근의 사망은 아직 알비온 쪽에 반영되지 않아 "킬보드 미검증" 으로 표시되는 경우가 많습니다. 시스템이 청구를 거절하는 대신 "재확인" 버튼을 노출해서, 30분 정도 후 다시 시도하면 통과하도록 만들었습니다. 이는 사이트 결함이 아니라 알비온 측 지연임을 자연스럽게 알리는 방식입니다.
