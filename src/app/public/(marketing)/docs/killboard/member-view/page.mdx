# 멤버 상세에서 보기

한 길드원의 멤버 상세 페이지에서 그 사람의 추적된 킬·데스만 모아 봅니다. 외부 킬보드 사이트와 달리 청구 매칭, 업적 진행도 같은 길드 컨텍스트가 같이 보입니다.

## 어떻게 동작하나

`/members/[디스코드ID]` 의 "최근 킬/데스" 섹션은 추적된 이벤트만 노출합니다. 한 줄 클릭으로 해당 이벤트의 상세 (어떤 인챈트로 죽었나, 어떤 청구가 자동 생성됐나 등) 가 펼쳐집니다.


## 규칙과 정책

### 길드 컨텍스트가 같이 보입니다

외부 킬보드는 "이 사람의 최근 킬·데스" 만 보여주지만, 길드 운영 입장에서는 "이 사망이 어떤 청구로 이어졌나", "이 킬이 어떤 업적에 카운트됐나" 가 더 중요합니다. 그래서 멤버 상세의 킬·데스 로그는 청구·업적과 같은 화면 안에서 볼 수 있게 묶어두었습니다.
