# 참가예정

참가예정은 슬롯이 아직 정해지지 않았을 때, 길드원이 “나는 오늘 참가 가능하고 이런 역할을 할 수 있다”를 먼저 남기는 기능입니다.

## 언제 쓰나

- 파티 조합이 아직 확정되지 않았을 때
- 멤버가 여러 역할을 할 수 있어 관리자가 나중에 배치하고 싶을 때
- 외부 일정 때문에 참가 가능 여부만 먼저 받고 싶을 때

## 슬롯 신청과의 차이

슬롯 신청은 특정 자리에 들어가는 행동입니다. 참가예정은 아직 자리를 고르지 않고 가능한 역할군만 올리는 행동입니다. 관리자가 슬롯을 확정하면 참가예정 목록을 보며 빠르게 배치할 수 있습니다.

## 운영 팁

이벤트마다 참가예정 모드를 켜고 끌 수 있습니다. 모든 이벤트에 강제로 쓰기보다, 조합을 늦게 확정하는 대규모 ZvZ나 연합전에서 쓰는 것이 좋습니다.
