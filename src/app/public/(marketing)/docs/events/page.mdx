## 왜 이벤트가 중심인가

AGM 은 단순한 관리자 도구가 아니라 길드원이 실제로 들어와 쓰는 운영 앱입니다. 길드원이 이벤트 상세 페이지에서 슬롯을 신청하고, 전투 후에는 출석·통계·리기어 청구가 이어집니다. 그래서 이벤트는 통계, 리기어, 포인트, 게스트 권한의 출발점입니다.
