# 이벤트 발행 / 알림

발행은 관리자가 준비한 초안을 길드원에게 공개하는 단계입니다. 발행 후에는 이벤트 상세 페이지가 길드원의 주 진입점이 되고, Discord 알림을 통해 바로 접근할 수 있습니다.

## 발행 후 달라지는 점

- 길드원 홈과 이벤트 목록에 노출됩니다.
- 이벤트 상세 페이지에서 슬롯 신청이 가능해집니다.
- 설정된 Discord 채널로 이벤트 안내 메시지를 보낼 수 있습니다.
- 집결 시간이 가까워지면 DM 안내를 보낼 수 있습니다.

## Discord 알림은 링크 중심입니다

알림의 목적은 Discord 안에서 모든 것을 처리하는 것이 아니라, 길드원을 이벤트 상세 페이지로 데려오는 것입니다. 이벤트 상세 페이지에서 현재 슬롯 상태, 신청자, 특이사항을 한 번에 확인해야 관리자가 Discord 댓글을 수동으로 정리하지 않아도 됩니다.

## 발행 후에도 수정은 가능합니다

집결 장소가 바뀌거나 슬롯이 추가될 수 있으므로, 발행 이후에도 관리자는 이벤트를 수정할 수 있습니다. 다만 이미 신청한 멤버에게 영향을 주는 변경은 운영 혼선을 줄이기 위해 Discord 재공지와 함께 처리하는 것을 권장합니다.
