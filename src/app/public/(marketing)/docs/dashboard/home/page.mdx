# 내 홈

`/me` 는 로그인 후 첫 진입 페이지입니다. 본인의 최근 활동을 한 화면에 모아 봅니다.

## 어떻게 동작하나

다음 카드들이 한 화면에 모입니다.

- 최근 ZvZ 참여 / 사망 요약
- 내가 제출 / 승인 대기 중인 리기어 청구
- 포인트 잔액 + 최근 적립·차감 내역
- 업적 진행도 (멤버 상세의 축약 버전)

## 규칙과 정책

### 어드민 화면과 완전히 분리되어 있습니다

어드민이 보는 화면은 "전 길드원의 청구 큐, 가격 적정성, 정황 검증" 이고, 멤버가 보는 화면은 "내 청구 1건, 내 가격 1개, 내 보상" 입니다. 같은 데이터를 다른 관점으로 보는 화면을 한 페이지에 섞으면 양쪽 모두 복잡해져서, 멤버용 / 어드민용 영역을 처음부터 분리했습니다.

### 멤버 공개 프로필과 내 홈은 다릅니다

내 홈은 본인이 보는 운영 화면 (청구 / 보상 / 설정), 멤버 상세는 누구나 볼 수 있는 길드원 프로필 (활동 / 업적 / 무기 통계) 입니다. 같은 데이터의 일부가 겹치지만 관점이 달라서, 운영 액션이 가능한 본인 화면과 공개 프로필을 분리해 권한 / 노출 정책을 단순하게 유지합니다.
