# 내 프로필

`/me/profile` 에서 알비온 캐릭터 인증 / 닉네임 / 디스코드 표시명 등을 관리합니다.

## 어떻게 동작하나

- 알비온 캐릭터 검색 → 본인 확인 → 디스코드 계정과 1:1 매칭
- 닉네임 / 디스코드 표시명 변경
- 알비온 길드를 떠난 경우 인증이 자동으로 풀리고 재인증을 안내


## 규칙과 정책

### 디스코드 ↔ 알비온 1:1 연결

길드 운영의 모든 데이터 (청구·통계·업적) 는 한 사람당 한 줄로 정렬돼야 의미가 있습니다. 한 사람이 여러 알비온 캐릭터를 쓰는 경우에도, 한 디스코드에 한 캐릭터를 묶는 정책으로 운영합니다 (필요하면 다른 캐릭터로 교체 가능).
