# 내 리기어 청구

`/me/regear/[id]` — 자동 또는 수동으로 만들어진 청구의 상세 화면입니다. 청구자가 가격·결제 모드를 본인 의사로 확정해 제출합니다.

## 어떻게 동작하나

- 6개 슬롯의 가격을 부위별로 편집
- 부위별 결제 모드 (실버 / 제작) 선택
- 검증 상태 (킬보드 매칭 통과 / 미검증) 확인 + 재확인 버튼
- 제출 후 어드민 승인 큐로 이동


## 규칙과 정책

### 자동 청구도 본인이 한 번 손대고 제출합니다

자동 매칭이 그대로 승인까지 가면 "내 빌드는 더 비싼데?", "이 부위는 왜 빠졌나?" 같은 분쟁이 생깁니다. 청구자가 자기 빌드를 한 번 검토 → 가격 / 결제 모드를 본인 의사로 확정 → 어드민 승인의 2단계 흐름이 책임과 신뢰성의 균형점입니다.
