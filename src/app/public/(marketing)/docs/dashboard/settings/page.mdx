# 내 설정

`/me/settings` — 길드 어드민이 정한 기본값을 본인 단위로 덮어쓸 수 있는 항목 (예: 이벤트 DM 알림 시점과 수신 여부) 을 관리합니다.

## 어떻게 동작하나

어드민 폼과 동일한 입력 패턴이라 "기본값 따르기" 같은 별도 옵션 없이, 본인이 본 값이 곧 적용되는 값입니다. 항목별로 직접 값을 지정하거나, 어드민이 정한 값을 그대로 두면 됩니다.


## 규칙과 정책

### 개인 설정은 어드민 폼과 같은 패턴

어드민 폼이 "직접 값 지정" 인데 멤버 설정만 "기본값 따르기 / 직접 지정" 식으로 섞어 두면 두 가지 사고가 납니다 — 어드민이 기본값을 바꿨을 때 멤버 화면이 의도와 다르게 변하거나, "기본값 따르기" 가 실제로 어떤 값인지 알 수 없게 됩니다. 같은 패턴으로 통일해서, 어드민·멤버 둘 다 자기가 본 값이 곧 적용되는 값이 되도록 했습니다.
