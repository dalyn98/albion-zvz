# 내 요청 / 보상 내역

`/me/requests` — 지금까지 제출한 청구의 상태와 보상 합계를 시간순으로 봅니다.

## 어떻게 동작하나

- 청구 상태 (대기 / 승인 / 반려 / 지급 완료) 별 필터
- 보상 합계 (실버 / 제작 별도)
- 시간 / 이벤트별 정렬

## 규칙과 정책

### 보상 흐름의 종착점

청구는 "제출 → 검증 → 승인 → 지급" 의 흐름을 거치는데, 멤버 입장에서는 자기 청구가 어디까지 왔는지 한 화면에서 추적하고 싶습니다. 이 페이지가 그 종착점 — 진행 중인 청구의 상태, 종료된 청구의 결과를 모두 시간순으로 정리해 보여줍니다.
