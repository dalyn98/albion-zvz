# 전투 상세

`/battles/[교전ID]` 에서는 자동 구분된 교전 하나의 판정과 근거를 봅니다. 직접 K/D, 킬페임, 상대별 근거와 원본 대조 상태가 한 화면에 모입니다.

## 어떻게 동작하나

- 교전 전체의 사실 K/D·킬페임과 결과 판정에 포함된 근거를 분리해서 표시
- 판정 대상, 개입 상대, 기타 이벤트를 상대별로 구분
- 원본 홈 길드 K/D와 수집한 직접 이벤트 K/D의 일치 여부 표시
- 해당 교전에 연결된 길드원의 킬·데스 로그


## 규칙과 정책

### 메모는 판정을 바꾸지 않습니다

운영자는 교전 맥락을 메모할 수 있지만 수동으로 교전을 합치거나 나눌 수는 없습니다. 메모는 설명용이며 교전 경계·수치·결과·통계에 영향을 주지 않습니다.

### 판정 전 상태도 숨기지 않습니다

원본 전투가 같은 내용으로 두 번 확인되지 않았거나 직접 이벤트가 아직 모두 수집되지 않았다면 `판정 중`으로 표시합니다. 신원이나 킬페임 근거가 불완전하면 `판정 차단`, 2~8분의 애매한 경계가 있으면 `교전 구분 필요`, 판정 대상 이벤트가 5건 미만이면 `판정 보류`로 표시합니다.
