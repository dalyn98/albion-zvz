# 전투 목록

`/battles` 에서 알비온의 원본 전투를 실제 교전 단위로 자동 구분한 결과를 보여줍니다. 각 카드에서 결과뿐 아니라 수집·보류 이유와 판정에 사용된 근거를 확인할 수 있습니다.

## 어떻게 동작하나

우리 길드의 직접 킬·데스 이벤트를 시간 흐름과 상대 전력으로 묶습니다. 원본 battle 하나 안에서도 교전이 끊겼다가 다시 시작되면 별도 교전이 될 수 있고, 같은 흐름에서 여러 상대가 등장하면 결과는 하나만 부여하되 상대별 근거를 나눠 보여줍니다.


## 규칙과 정책

### 전력 규모는 결과의 조건입니다

아군 측이 20명 이상이고, 같은 교전에서 **개입 상대**를 제외한 상대 전력의 인원 합계도 20명 이상이어야 공식 결과에 포함됩니다. 개별 상대가 20명 미만이어도 합계가 기준을 충족하면 하나로 합치지 않고 1:N 매치업으로 각각 표시합니다. 규모 미달 이벤트도 삭제하지 않고 **기타 교전 근거**로 남기지만 결과·통계·업적에는 반영하지 않으며, 전력 규모 자체가 우세나 열세를 뒤집지는 않습니다.

### K/D와 킬페임을 함께 봅니다

판정 대상 직접 이벤트가 5건 이상이어야 합니다. K/D 비율과 킬페임 비율이 같은 방향으로 각각 20% 이상 차이 날 때만 교전 우세·열세이며, 방향이 다르거나 어느 한쪽의 차이가 20% 미만이면 박빙입니다. 근거가 부족하거나 수집이 끝나지 않은 경우에는 판정을 보류합니다.

### 여러 상대가 있어도 교전 결과는 하나입니다

같은 흐름에서 B와 C를 동시에 상대했다면 B전·C전으로 결과를 복제하지 않습니다. 교전 전체 결과 하나와 상대별 K/D·킬페임 근거를 표시합니다. 주 상대가 있는 상태에서 직접 이벤트가 단 한 건뿐인 두 번째 상대는 **개입 상대**로 표시하고 결과에서는 제외합니다.

### 애매한 시간 간격은 자동 확정하지 않습니다

직접 이벤트 간격이 2분 이내면 같은 교전, 8분 이상이면 별도 교전입니다. 2분 초과 8분 미만은 `교전 구분 필요`로 남깁니다. 운영자 메모는 설명만 추가하며 교전 구분·수치·판정·통계를 바꾸지 않습니다.
