# 내 사이펀

사이펀은 알비온 온라인에서 길드가 어디서든 꺼내 쓸 수 있는 재화라, 일반 장비처럼 특정 보관함 위치만 보고 추적하기 어렵습니다. AGM 의 사이펀 기능은 개인별 입금·출금 내역을 장부로 남겨 길드원 본인이 잔여 수량을 직접 확인할 수 있게 합니다.

## 길드원이 보는 화면

`/me` 의 내 정보 영역에서 현재 사이펀 잔액, 누적 입금, 누적 출금, 최근 활동을 확인합니다. 길드원이 “내가 넣은 사이펀이 얼마나 남았는지”를 관리자에게 물어보지 않아도 되는 것이 목적입니다.

`/me/siphon` 에서는 본인 기준 거래 내역을 최신순으로 볼 수 있습니다. 입금은 양수, 출금은 음수로 표시되며, 관리자가 남긴 메모가 있으면 함께 노출됩니다.

## 관리자가 입력하는 방식

관리자는 어드민 사이드바의 `사이펀 관리`에서 인게임 사이펀 입출금 로그를 붙여넣어 길드원별 입금·출금 내역을 추가합니다. 알비온 캐릭터 인증이 된 멤버는 Discord 계정과 캐릭터명이 연결되어 있어, 장부와 실제 게임 내 활동을 대조하기 쉽습니다.

기존에 쌓인 로그가 불완전하다면 먼저 `사이펀 관리 → 로그 운영 시작시간`에서 사이펀 기준 시각을 정합니다. 같은 값은 `설정 → 길드`에서도 확인할 수 있습니다. 기준 시각 이전 행은 공식 잔액, 멤버 내역, 관리자 목록에서 제외되므로 과거 일부 로그가 남아 있어도 새 운영 시작점부터 깨끗하게 계산할 수 있습니다.

운영 흐름은 보통 다음과 같습니다.

1. 길드원이 사이펀을 길드에 맡기거나 사용 요청을 합니다.
2. 담당관이 운영 시작시간을 확인한 뒤 날짜 / 플레이어 / 목적 / 수량 로그를 붙여넣습니다.
3. import 미리보기에서 중복, 기준 전 스킵, 로그 공백 경고를 확인합니다.
4. 길드원은 `/me` 또는 `/me/siphon` 에서 잔여 수량을 확인합니다.
5. 분쟁이 생기면 관리자 감사 로그와 사이펀 장부를 함께 확인합니다.

## 로그 초기화

잘못된 파일을 저장했거나 과거 불완전 로그가 섞여 장부가 오염된 경우 `사이펀 관리`의 `사이펀 로그 초기화`를 사용합니다. 초기화는 현재 길드의 사이펀 원본 로그만 삭제하고, 멤버별 사이펀 잔액은 0으로 다시 계산됩니다.

운영 시작시간 설정은 초기화해도 유지됩니다. 따라서 기준 시각을 먼저 정하고, 오염된 로그를 초기화한 뒤 같은 기준으로 새 로그를 다시 import 하는 흐름이 가장 안전합니다. 초기화 자체도 감사 로그에 남습니다.

## 권한

사이펀 장부를 수정하려면 `SIPHON_MANAGE` 권한이 필요합니다. 길드장은 권한 관리 화면에서 특정 Discord 역할이나 특정 사용자에게만 이 권한을 줄 수 있습니다.

사이펀은 현금성 결제 기능이 아니라 길드 내부 재화 장부입니다. 다만 길드 운영 분쟁으로 이어질 수 있으므로, 입력 담당자는 최소화하고 감사 로그를 함께 켜 두는 것을 권장합니다.
