# Albion 계정 입장

Albion 계정 입장은 Discord 로그인이 부담스러운 길드원이나 외부 동맹이 길드 사이트를 제한적으로 사용할 수 있게 하는 길드 전용 로그인입니다. Discord 비밀번호나 Albion 게임 계정 비밀번호를 요구하지 않고, 사이트 안에서만 쓰는 비밀번호와 길드 초대 코드로 계정을 만듭니다.

## 왜 필요한가

일부 사용자는 사설 사이트에 Discord 로그인을 누르는 것 자체를 부담스러워합니다. 또 동맹이나 외부 용병처럼 Discord 서버에 정식으로 들어오지 않은 사람이 이벤트 페이지와 리기어 신청만 써야 하는 경우도 있습니다.

이때 관리자가 길드 초대 코드를 공지해 두면, 사용자는 다음 정보로 길드 전용 계정을 만들 수 있습니다.

- Albion 서버
- Albion 닉네임
- 이 사이트에서만 사용할 비밀번호
- 길드에서 공지한 초대 코드

## 사용할 수 있는 기능

Albion 계정은 의도적으로 범위를 좁게 둡니다.

- 이벤트 확인과 슬롯 신청
- 리기어 신청

멤버 목록, 길드 통계, 관리자 기능, 다른 길드 페이지 접근은 사용할 수 없습니다. 더 많은 기능이 필요하면 Discord 로그인을 사용해야 합니다.

## 신뢰 기준

계정 생성 시 Albion Gameinfo 에서 닉네임을 확인하고, 홈 길드 로스터와 일치하면 해당 길드 기능을 사용할 수 있는 신뢰 계정으로 처리합니다. 길드 관리자는 설정에서 미인증 멤버 접근과 리기어 검증 정책을 함께 조정해 재화 기능의 위험도를 낮출 수 있습니다.

## 관리자 설정 위치

어드민 → 설정 → 길드 탭에서 **Albion 계정 로그인**을 켜고 길드 초대 코드를 설정합니다. 초대 코드는 평문으로 저장하지 않고 해시만 저장합니다. 코드가 외부로 퍼졌다고 판단되면 같은 위치에서 새 코드로 교체하세요.
