# 설정 마법사

봇 초대와 디스코드 로그인을 끝내면 자동으로 열리는 마법사입니다. 시간대, Discord 역할, 공지 채널, 알비온 홈 길드, 리기어 보상 정책을 순서대로 정합니다.

## 어떻게 동작하나

세 단계를 순서대로 진행합니다.

1. **기본 정보** — 길드 시간대, 멤버 역할, 관리자 역할, 이벤트 공지 채널을 정합니다
2. **알비온 홈 길드** — 추적할 알비온 길드를 검색해서 선택합니다 (Americas / Asia / Europe 서버 중 하나). 이때 사이트 주소도 홈 길드 이름 기반으로 자동 정리됩니다
3. **보상 정책** — 자동 리기어 켜기/끄기, 기본 보상 비율 등. 나중에 어드민 설정에서 언제든 바꿀 수 있습니다


## 규칙과 정책

### 사이트 주소는 알비온 홈 길드 기준으로 자동 정리됩니다

디스코드 길드명은 한글·이모지·띄어쓰기를 허용해서 인터넷 주소에 그대로 쓸 수 없습니다. 그래서 사이트 주소는 알비온 홈 길드 이름을 우선해 영문 slug 로 맞추고, 홈 길드를 아직 정하지 않은 경우에는 봇 설치 시 생성된 임시 주소를 사용합니다.

처음 홈 길드를 고르면 주소와 공개 메타데이터가 자연스럽게 정리됩니다. 운영 중 홈 길드를 바꾸는 일은 킬보드·통계 기준도 함께 바뀌는 큰 작업이라 일반 설정에서는 잠그고, 필요한 경우 운영자 확인을 거칩니다.

### 보상 정책은 마법사에서 정하고 나중에 바꿉니다

처음부터 모든 정책을 깊게 결정하기 어려우므로, 마법사 단계에서는 안전한 기본값을 제시하고 어드민 설정에서 언제든 조정할 수 있게 했습니다.

완료 후 대시보드의 체크리스트에서 공개 길드 프로필, 빌드표, Albion 계정 입장, 자동/제작 리기어 같은 선택 기능을 이어서 켤 수 있습니다.
