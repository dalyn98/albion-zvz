# Discord 운영 흐름

AGM의 Discord 기능은 사이트를 대체하는 명령어 묶음이 아닙니다. 길드원이 이미 머무는 Discord에서 "지금 어디로 가야 하는지"를 짧게 판단하게 만들고, 실제 신청·승인·편집·기록은 사이트에서 이어서 처리하게 하는 보조 조종판입니다.

가이드의 기준은 명령어 이름이 아니라 상황입니다. 아래 표에서 현재 상황을 먼저 찾고, 필요한 명령어나 패널을 사용하세요.

## 상황별 빠른 선택

| 상황 | 사용 | 이어지는 화면 |
| --- | --- | --- |
| 봇을 초대했지만 사이트 설정이 끝나지 않았음 | `/agm setup` | 설정 마법사 |
| 멤버가 "사이트 어디로 들어가요?"라고 물어봄 | `/agm quick` | 주요 화면 버튼 |
| 멤버가 명령어 자체를 모름 | `/agm help` | 명령어 안내 |
| 기능 설명을 반복해서 해야 함 | `/agm guide` | 문서/빠른 가이드 |
| 이벤트·리기어·상점·제작 화면으로 바로 가고 싶음 | `/agm open page` | 선택한 기능 화면 |
| 내 정보와 인증 상태를 확인해야 함 | `/agm me profile`, `/agm me verify` | 내 정보 / Albion 인증 |
| 포인트만 빠르게 확인하거나 출금 요청을 만들고 싶음 | `/agm wallet balance`, `/agm wallet withdraw` | 지갑 / 요청 내역 |
| 관리자가 운영 화면으로 바로 가야 함 | `/agm admin dashboard` | 관리자 대시보드 |
| 예외 포인트 보정을 기록으로 남겨야 함 | `/agm admin points` | 멤버 상세 / 감사 로그 |
| 신규 멤버 안내 버튼을 채널에 고정하고 싶음 | `/agm admin quick-publish` | Quick Starter Panel |
| 킬봇·전투 알림 상태를 점검해야 함 | `/agm admin killbot` | Killbot 가이드 / 설정 |

## 왜 Discord에서 시작하나

Discord 명령은 "설명"보다 "진입"을 줄이기 위해 있습니다. 전투 직전 모바일에서 메뉴를 찾거나, 새 멤버가 사이트 주소를 다시 묻거나, 운영자가 같은 안내를 반복하는 상황을 줄이는 것이 목적입니다.

- 채널에 긴 설명을 남기지 않고 본인에게만 보이는 응답으로 안내합니다.
- 멤버 개인 할 일은 기능 페이지 본문을 가리지 않고 내 정보·지갑·요청 내역으로 보냅니다.
- 관리자가 사이트를 계속 보고 있지 않아도 Discord 알림, 승인 버튼, 관리자 배지로 승인 대기를 발견하고 빠르게 처리합니다.
- 예외적인 포인트 조정이나 출금 요청은 DM/구두 요청이 아니라 기록이 남는 흐름으로 만듭니다.

## 어디까지 Discord에서 처리하나

Discord에서는 짧은 확인, 링크 제공, 안내 버튼, 출금 요청 생성처럼 "시작점"에 가까운 작업을 합니다. 지원되는 운영 알림은 승인/거절 버튼으로 바로 처리할 수 있고, 가격 수정·상세 검토·권한 변경처럼 맥락이 필요한 작업은 사이트에서 처리합니다.

- 이벤트 생성, 파티 편집, 보상 확정: 사이트
- 리기어 실버 승인, 재고 출고, 제작 큐 전환, 환전/포인트 환전 승인: Discord 알림 버튼 또는 사이트
- 상점 가격, 재고, 제작 큐 관리: 사이트
- 빠른 진입, 잔액 확인, 출금 요청, 운영 알림: Discord
