# Discord 운영 흐름

AGM Discord 명령은 단순 링크 모음이 아니라, 짧은 조회와 안전한 상태 변경을 Discord 안에서 끝내고 상세 편집만 웹으로 이어 주는 운영 도구입니다. 모든 결과는 현재 Discord 서버에 연결된 길드와 실행자 권한으로 제한됩니다.

## 상황별 빠른 선택

| 상황 | 사용할 명령 |
| --- | --- |
| 봇을 초대했지만 설정이 끝나지 않음 | `/agm setup` |
| 내 전체 상태를 먼저 확인 | `/agm me summary` |
| 이벤트 참가·슬롯·내 상태·취소 | `/agm event next`, `browse`, `status`, `cancel` |
| 잔액·송금·출금·장부 확인 | `/agm wallet balance`, `send`, `withdraw`, `history` |
| 내 통계·길드원 통계·순위·전투 확인 | `/agm stats me`, `member`, `leaderboard`, `battle` |
| 리기어 가능 여부와 신청 상태 | `/agm regear eligible`, `status` |
| 제작 작업 수주부터 납품·수령까지 | `/agm craft queue`, `mine`, `claim`, `release`, `deliver`, `pickup` |
| 사이폰 잔액과 내역 | `/agm siphon balance`, `history` |
| 상점 주문 상태·주문·재주문 | `/agm shop status`, `order`, `reorder` |
| 승인 큐와 이벤트 운영 | `/agm admin approvals`, `event-create`, `event-start` |
| 포인트 예외 보정·안내 패널·관리 화면 | `/agm admin points`, `quick-publish`, `dashboard` |

## Discord에서 바로 끝나는 일

- 포인트 잔액·장부, 통계, 리기어·주문·제작·사이폰 상태 조회
- 이벤트 신청 상태 확인과 본인 신청 취소
- 길드원 간 포인트 전송과 출금 요청 생성
- 단일 카탈로그 상품 주문과 안전한 단일 품목 재주문
- 제작 작업 수주, 반납, 납품, 수령 확인
- 권한이 있는 관리자의 승인 처리, 이벤트 초안 생성, 예외적인 조기 운영 시작

각 상태 변경은 웹 기능과 같은 테넌트 범위, 권한, 원자적 RPC 또는 감사 로그를 사용합니다.

## 웹으로 이어지는 일

정책 계산이나 편집 맥락이 긴 작업은 Discord에서 부정확하게 축약하지 않습니다.

- 정확한 리기어 신청 가능 목록과 실제 신청
- 여러 품목 상점 주문, 가격 견적이 필요한 상품, 여러 품목 재주문
- 이벤트 파티·슬롯 세부 편집, 상점 가격·재고, 권한·정책 설정
- 관리자 전체 대시보드와 상세 감사 기록

Discord 응답의 `웹에서 열기` 버튼은 현재 길드의 정확한 화면으로 연결됩니다. 인증이 필요한 화면은 서명된 Discord 인터랙션에서 만든 일회성 로그인 흐름을 사용합니다.

## 응답과 보안 원칙

- 슬래시 명령은 먼저 비공개 응답을 예약해 Discord의 3초 제한을 지킵니다.
- 이벤트·전투·제작 작업·상품·주문 선택지는 현재 길드 데이터만 자동완성합니다.
- 일반 멤버 명령은 활성 길드 연결이 필요합니다.
- 관리자 명령은 사이트 관리자 또는 세분화된 capability를 다시 확인합니다.
- 사용자 입력 ID, 수량, 메모 길이와 현재 상태를 실행 직전에 검증합니다.
