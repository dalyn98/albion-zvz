# Discord 명령어별 사용 상황

모든 명령어는 `/agm` 아래에 있습니다. 명령어를 외우기보다, 지금 겪는 상황에 맞춰 선택하세요. 응답은 기본적으로 본인에게만 보이므로 공개 채널을 어지럽히지 않습니다.

## `/agm setup`

### 이런 상황 때 사용하세요

- 봇을 막 초대했고 아직 사이트 설정이 끝나지 않았습니다.
- 설정 마법사를 중간에 닫아서 다시 이어가야 합니다.
- Discord 서버와 AGM 사이트가 연결되어 있는지 처음 확인해야 합니다.

### 왜 이 흐름인가

새 길드가 관리자에게 별도 SQL 처리나 수동 세팅을 요청하지 않고 직접 시작할 수 있게 하기 위한 출발점입니다. 이미 활성화된 길드라면 관리자 대시보드로 보내고, 설정 중인 길드라면 기존 설정 마법사를 이어갑니다.

### 주의

새 설정을 만들려면 Discord 서버의 관리자 또는 서버 관리 권한이 필요합니다. 이미 설정 중인 길드는 처음 설치한 사용자만 이어갈 수 있습니다.

## `/agm quick`

### 이런 상황 때 사용하세요

- 멤버가 "사이트 링크 어디예요?", "리기어 어디서 해요?"라고 묻습니다.
- 신규 멤버에게 인증, 이벤트, 내 정보, 리기어, 상점, 지갑, 가이드를 한 번에 안내하고 싶습니다.
- 운영자가 매번 URL을 복사해서 설명하고 있습니다.

### 왜 이 흐름인가

길드원이 Discord 안에서 바로 주요 화면 버튼을 받도록 만든 명령입니다. 기능 페이지 본문에 큰 할 일 목록을 넣지 않고, 필요할 때 Discord 버튼으로 각 화면에 진입하게 하는 역할입니다.

## `/agm help`

### 이런 상황 때 사용하세요

- 멤버가 AGM에서 어떤 Discord 명령을 쓸 수 있는지 모릅니다.
- 새 명령어가 추가되었고 간단히 안내해야 합니다.

### 왜 이 흐름인가

채널에 긴 설명을 반복하지 않고, 명령어 자체를 Discord 안에서 self-serve로 확인하게 하기 위해 있습니다.

## `/agm guide`

### 이런 상황 때 사용하세요

- 기능 사용법을 물어보는 멤버가 있습니다.
- 리기어, 지갑, 상점, 이벤트 같은 개념 설명을 반복하고 있습니다.
- 명령어보다 문서로 안내하는 편이 더 정확한 상황입니다.

### 왜 이 흐름인가

Discord 명령어는 작업을 시작하게 하는 도구이고, 자세한 설명은 문서가 맡아야 합니다. `/agm guide`는 운영자가 같은 설명을 반복하지 않고 문서와 빠른 가이드로 보내기 위한 명령입니다.

## `/agm open page`

### 이런 상황 때 사용하세요

- 목적지는 알지만 메뉴를 찾아 들어가기 번거롭습니다.
- 전투 직전 모바일에서 이벤트 화면을 빨리 열어야 합니다.
- 리기어, 상점, 제작 화면으로 바로 이동해야 합니다.

### 선택 기준

| page | 이런 때 선택 |
| --- | --- |
| `home` | 길드 홈, 오늘 활동, 기본 진입점을 열 때 |
| `events` | 참가 신청, 파티 확인, 전투 전 준비를 할 때 |
| `regear` | 장비 보상 신청이나 내 리기어 상태를 확인할 때 |
| `shop` | 포인트로 장비를 구매하거나 상점 상태를 볼 때 |
| `craft` | 제작 큐, 제작 작업, 픽업 흐름을 확인할 때 |

## `/agm me profile`

### 이런 상황 때 사용하세요

- 내 포인트, 요청, 인증 상태, 활동 요약을 한 번에 보고 싶습니다.
- 이벤트·리기어·상점 페이지를 돌아다니지 않고 내 상태부터 확인하고 싶습니다.

### 왜 이 흐름인가

멤버 개인 상태는 `/me`에 모으는 것이 원칙입니다. 각 기능 페이지가 "내 할 일"로 덮이지 않게 하고, 개인 확인은 내 정보 화면에서 이어지게 합니다.

## `/agm me verify`

### 이런 상황 때 사용하세요

- Albion 닉네임 인증이 안 되어 있습니다.
- Discord 역할이 바뀌었는데 사이트 권한이나 멤버 인식이 이상합니다.
- 신규 멤버가 처음 들어왔습니다.
- Discord 닉네임을 Albion 닉네임 기준으로 맞추고 싶습니다.

### 왜 이 흐름인가

AGM의 통계, 리기어, 킬보드, 닉네임 동기화는 Discord 계정과 Albion 캐릭터 연결을 기준으로 움직입니다. 인증을 다시 시작해야 할 때 이 명령을 사용합니다.

## `/agm wallet open`

### 이런 상황 때 사용하세요

- 포인트 내역, 요청 내역, 지갑 상세를 보고 싶습니다.
- 잔액 숫자만이 아니라 왜 변했는지 확인해야 합니다.

### 왜 이 흐름인가

단순 잔액은 Discord에서 확인할 수 있지만, 내역과 요청 상태는 사이트 지갑에서 보는 것이 맞습니다.

## `/agm wallet balance`

### 이런 상황 때 사용하세요

- 상점 구매나 출금 신청 전에 잔액만 빠르게 확인하고 싶습니다.
- 전투 중이거나 모바일이라 사이트를 열기 어렵습니다.

### 왜 이 흐름인가

단순 조회는 Discord에서 짧게 끝내기 위해 만든 명령입니다. 총 잔액, 보류 중인 금액, 실제 사용 가능한 금액을 구분해서 안내합니다.

### 주의

길드 멤버로 인식되지 않으면 Albion 인증 화면으로 이동해야 합니다.

## `/agm wallet withdraw amount`

### 이런 상황 때 사용하세요

- 포인트를 실버 지급 요청으로 전환하고 싶습니다.
- 운영자에게 DM으로 "포인트 빼주세요"라고 요청하던 흐름을 기록 남는 요청으로 바꾸고 싶습니다.

### 왜 이 흐름인가

출금 요청은 승인 큐에 남아야 합니다. 이 명령은 잔액 부족, 인증 누락, 중복 pending 요청을 자동으로 막고, 관리자에게 환전 승인 알림을 보냅니다.

### 주의

Albion 인증이 필요합니다. 이미 처리되지 않은 출금 요청이 있으면 새 요청을 만들 수 없습니다.

## `/agm admin dashboard`

### 이런 상황 때 사용하세요

- Discord에서 운영 이슈를 보고 바로 관리자 화면을 열어야 합니다.
- 승인 큐, 이벤트, 상점, 설정 중 어느 화면으로 갈지 아직 정하지 않았습니다.

### 왜 이 흐름인가

Discord는 문제를 발견하는 장소이고, 실제 처리는 관리자 대시보드에서 하는 구조입니다.

## `/agm admin points member delta memo`

### 이런 상황 때 사용하세요

- 이벤트 보상이 누락되었습니다.
- 포인트가 잘못 지급되어 정정해야 합니다.
- 운영 사유를 남긴 예외 보정이 필요합니다.

### 왜 이 흐름인가

포인트는 직접 덮어쓰면 안 됩니다. 이 명령은 웹 UI와 같은 append-only 장부 경로를 사용해서 누가, 누구에게, 얼마를, 왜 조정했는지 남깁니다.

### 주의

일반 지급 루틴을 대신하는 명령이 아닙니다. 반드시 `memo`에 운영 사유를 남기세요.

## `/agm admin quick-publish`

### 이런 상황 때 사용하세요

- 신규 멤버가 계속 들어오고 같은 안내를 반복합니다.
- 채널에 "인증/이벤트/내 정보/리기어/상점/지갑" 버튼을 고정형으로 두고 싶습니다.
- 이미 게시한 Quick Starter Panel을 업데이트해야 합니다.

### 왜 이 흐름인가

멤버가 매번 운영자에게 묻지 않고 스스로 필요한 화면으로 들어가게 하기 위한 관리자용 게시 명령입니다. 같은 채널에 기존 패널이 있으면 업데이트하고, 없으면 새로 게시합니다.

## `/agm admin killbot`

### 이런 상황 때 사용하세요

- 킬봇 피드가 안 보입니다.
- 전투 알림이나 killbot 설정 화면으로 바로 가야 합니다.
- Discord 전투 알림 운영을 점검해야 합니다.

### 왜 이 흐름인가

킬봇 문제는 Discord에서 가장 먼저 체감됩니다. 명령은 가이드와 설정 화면으로 빠르게 보내고, 실제 설정은 사이트에서 처리하게 합니다.
