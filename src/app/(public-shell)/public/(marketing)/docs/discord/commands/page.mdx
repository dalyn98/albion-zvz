# Discord 명령어 전체 안내

모든 명령어는 `/agm` 아래에 있고 응답은 기본적으로 실행한 사람에게만 보입니다. 선택 항목은 Discord 자동완성으로 현재 길드의 이벤트·전투·제작 작업·상품·주문만 보여 줍니다.

## 시작과 계정

| 명령어 | Discord에서 하는 일 | 웹으로 이어지는 경우 |
| --- | --- | --- |
| `/agm setup` | 새 길드 설정을 만들거나 중단한 설정을 이어갑니다. | 설정 마법사 또는 관리자 대시보드 |
| `/agm login code` | 공유 URL의 브라우저에 표시된 1회용 코드를 승인합니다. | 원래 공유 URL |
| `/agm help` | 현재 사용할 수 있는 멤버 명령을 한눈에 보여 줍니다. | 없음 |
| `/agm me summary` | 포인트, 대기 요청, 다음 이벤트를 요약합니다. | 내 정보 |
| `/agm me verify` | Discord 멤버십을 갱신하고 Albion 인증을 시작합니다. | 인증 화면 |

새 길드 생성은 Discord의 서버 관리 권한이 필요합니다. 이미 설정 중인 길드는 최초 설치자가 이어갑니다. 브라우저 로그인 코드는 5분 동안 한 번만 유효하며, 코드를 만든 원래 브라우저에만 세션이 발급됩니다.

## 이벤트

| 명령어 | 동작 |
| --- | --- |
| `/agm event next` | 다음 모집 이벤트와 참가 버튼을 보여 줍니다. |
| `/agm event browse` | 다음 이벤트의 신청 가능한 슬롯을 Discord에서 탐색합니다. |
| `/agm event status` | 다음 이벤트의 내 배정·신청 상태를 확인합니다. |
| `/agm event cancel event` | 자동완성으로 고른 이벤트의 내 배정·대기 신청을 취소합니다. |

취소는 실행자 자신의 데이터만 지우며 다른 멤버의 배정은 변경하지 않습니다. 일반 전투 이벤트는 전투 시작 후 취소할 수 없지만, FF·갱킹은 기존 정책에 따라 전투 시작 후에도 취소할 수 있습니다. 빌드 시트 모집 신청·배정은 웹 이벤트 화면에서 취소합니다.

## 포인트 지갑

| 명령어 | 동작 |
| --- | --- |
| `/agm wallet balance` | 총 포인트, 보류액, 실제 사용 가능 포인트를 확인합니다. |
| `/agm wallet send member amount memo` | 활성 길드원에게 포인트를 원자적으로 전송합니다. |
| `/agm wallet withdraw amount` | 실버 지급을 위한 출금 승인 요청을 생성합니다. |
| `/agm wallet history` | 최근 포인트 장부 내역을 확인합니다. |

전송은 자기 자신에게 할 수 없고, 보유한 사용 가능 포인트를 넘길 수 없습니다. 출금은 Albion 인증이 필요하며 pending 요청은 하나만 유지됩니다.

## 전투 통계

| 명령어 | 동작 |
| --- | --- |
| `/agm stats me window` | 내 킬·데스·참여·생존·승패 통계를 봅니다. |
| `/agm stats member member window` | 특정 활성 길드원의 같은 통계를 봅니다. |
| `/agm stats leaderboard metric window` | 킬, 참여, 생존율, K/D, 승률 순위를 봅니다. |
| `/agm stats battle battle` | 자동완성으로 선택한 추적 전투의 양 팀 요약을 봅니다. |

통계는 웹과 같은 추적 전투 집계와 최소 표본 규칙을 사용합니다. `window`은 이번 주, 최근 30일, 전체 중 선택합니다.

## 리기어와 제작

| 명령어 | 동작 |
| --- | --- |
| `/agm regear eligible` | 전투 추적·역할 정책·신청 한도를 모두 적용한 정확한 신청 가능 화면을 엽니다. |
| `/agm regear status` | 최근 리기어 신청과 지급 상태를 확인합니다. |
| `/agm craft queue` | 수주 가능한 제작 작업을 확인합니다. |
| `/agm craft mine` | 내가 수주한 제작 작업을 확인합니다. |
| `/agm craft claim task` | 대기 중 제작 작업을 수주합니다. |
| `/agm craft release task` | 내 작업을 대기열로 돌려보냅니다. |
| `/agm craft deliver task box material-cost` | 완성품을 상자에 납품하고 재고·요청자 알림을 갱신합니다. |
| `/agm craft pickup task` | 요청자가 제작 리기어 수령을 확정합니다. |

수주·납품은 등록된 크래프터 또는 해당 관리자만 사용합니다. 반납은 작업 소유자, 수령 확인은 리기어 요청자만 실행할 수 있으며 `task`는 현재 상태와 실행자에 맞는 작업만 자동완성합니다.

## 사이폰과 상점

| 명령어 | 동작 |
| --- | --- |
| `/agm siphon balance` | 인증된 Albion 캐릭터의 사이폰 순잔액을 확인합니다. |
| `/agm siphon history` | 최근 사이폰 입출고를 확인합니다. |
| `/agm shop status` | 내 최근 주문 상태를 확인합니다. |
| `/agm shop order item quantity memo` | 자동완성으로 고른 단일 카탈로그 상품을 현재 재고·가격으로 주문합니다. |
| `/agm shop reorder order memo` | 단일 품목이었던 최근 주문을 현재 재고·가격으로 반복합니다. |

가격 확인이나 멤버 견적이 필요한 상품, 여러 품목으로 구성된 재주문은 안전하게 웹 상점으로 연결됩니다.

## 관리자

| 명령어 | 필요한 권한과 동작 |
| --- | --- |
| `/agm admin approvals kind` | 자신이 처리할 권한이 있는 대기 요청과 승인·거절 버튼만 보여 줍니다. |
| `/agm admin event-create title category` | 해당 이벤트 종류 생성 권한으로 초안을 만듭니다. |
| `/agm admin event-start event` | 이벤트 관리자 또는 해당 종류의 본인 이벤트 생성자가 전투 시작을 기록합니다. |
| `/agm admin points member delta memo` | 사이트 관리자만 append-only 장부에 포인트 보정을 남깁니다. |
| `/agm admin quick-publish message` | 현재 채널의 길드원 안내 패널을 게시하거나 갱신합니다. |
| `/agm admin dashboard` | 관리자 대시보드로 안전한 일회성 로그인 링크를 만듭니다. |

승인과 상태 변경은 항상 현재 길드 범위로 제한되고, 기존 서비스와 같은 권한·감사 기록 경로를 사용합니다.

## 삭제된 중복 명령어

`/agm quick`, `/agm guide`, `/agm open`, `/agm me profile`, `/agm wallet open`, `/agm admin killbot`은 제거되었습니다. 같은 기능은 위의 구체적인 조회·작업 명령이나 `/agm admin quick-publish`, 웹 대시보드에서 처리합니다.
