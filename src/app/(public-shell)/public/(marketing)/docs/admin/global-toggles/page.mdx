# 글로벌 토글과 운영 상태

자동 리기어, 이벤트 자동 시작, 관리자 알림, 공개 페이지처럼 어드민이 직접 켜고 끄는 기능 토글과, 킬보드·전투 추적처럼 운영 패널에서 지연 여부를 감시하는 상태 지표를 구분해 봅니다.

## 어떻게 동작하나

설정 화면에 노출된 토글은 어드민이 한 번 클릭하면 해당 기능의 동작 범위가 즉시 바뀝니다. 반면 `last_*_sync_at` 같은 값은 마지막 성공 시각을 기록하는 상태값이며, 끄고 켜는 스위치가 아닙니다.


## 규칙과 정책

### 자동 작업은 글로벌 토글로 통째로 끌 수 있습니다

자동 리기어가 의도하지 않은 청구를 양산하기 시작하면 (예: 알비온 데이터 변경, 잘못된 길드명 매칭) 한 번에 멈출 수단이 필요합니다. 토글을 OFF 로 두면 자동 작업이 아예 돌지 않으므로, 데이터가 더 들어오기 전에 원인 파악 시간을 확보할 수 있습니다.

## 주요 토글 목록

### 리기어 · 보상

- **자동 리기어 (auto_regear_enabled)** — 블랙존 사망을 5분 주기로 스캔해 청구를 자동 생성합니다. OFF 면 정기 작업이 아예 돌지 않습니다
- **제작 리기어 (craft_regear_enabled)** — 신규 리기어를 길드 단위 제작 후보로 생성합니다. OFF 면 신규 신청은 실버 모드, ON 이면 어드민 승인 단계에서 제작 큐 / 재고 출고 / 실버 전환을 선택합니다
- **자동 청구 제외 슬롯 (auto_regear_excluded_slots)** — 음식 · 망토 · 탈것 · 포션 등 자동 청구에서 빼고 싶은 슬롯을 어드민이 직접 선택합니다 (기본값: 음식 · 망토 · 탈것 · 포션)
- **신뢰도 낮은 슬롯 자동 제외 (auto_regear_skip_low_confidence)** — 기준 도시 밖의 블루존/레드존 확장이나 단일 표본으로만 가격이 잡힌 슬롯을 청구에 포함하지 않고 청구자가 직접 추가하도록 유도합니다

### 시세 산정 (AODP)

- **기준 도시 (aodp_cities)** — 시세 추정에 쓸 홈 거래소 1곳. 이 도시를 1순위로 쓰고, 데이터가 없으면 다른 로열 도시 중앙값 → 블루존/레드존 확장 순서로 폴백합니다
- **가격 모드 (aodp_price_mode)** — 현재가 또는 최근 1/3/7/14일 수량 가중 평균 중 하나를 선택합니다
- **최소 품질 (aodp_min_quality)** — 드랍 아이템 품질이 이 값보다 낮으면 이 품질로 끌어올려 조회합니다. 기본 1은 보정 없음입니다

### 이벤트

- **이벤트 자동 시작 (events_auto_start_enabled)** — 모집 시간이 지나면 이벤트를 자동으로 "진행 중" 으로 전환합니다
- **이벤트 DM 안내 (event_dm_lead_minutes)** — 모임 시각 N 분 전 참가자에게 디스코드 DM 발송
- **참가예정 모드** — 슬롯이 정해지기 전 멤버가 가능 역할군을 미리 표시할 수 있는 흐름 (이벤트별 ON / OFF)
- **솔로 폭딜러 슬롯** — 1명짜리 솔로 폭딜 슬롯을 별도로 표시해 일반 슬롯과 분리 운영

### Discord 알림

- **이벤트 채널 공지** — 이벤트를 발행하거나 수정한 뒤 운영자가 직접 전송하는 역할 멘션 공지입니다
- **개인 DM 알림 (event_dm_lead_minutes)** — 길드 기본값과 멤버 개인 설정에 따라 집결 전 DM 을 보냅니다
- **관리자 운영 알림 (admin_notifications_*)** — 승인 대기, 상점 주문, 제작 납품, 동기화 지연, 미인증 멤버를 운영자 전용 채널로 보내고, 필요하면 30분/1시간/3시간/하루 단위로 요약합니다

### 통계 · 동기화 상태

- **킬보드 동기화 상태 (last_killboard_sync_at)** — 마지막 성공 시각입니다. 어드민 운영 패널은 이 값이 오래되면 동기화 지연으로 표시합니다
- **전투 추적 상태 (last_battle_tracker_sync_at)** — `/battles` 기반 전투 집계의 마지막 성공 시각입니다. 자동 리기어 매칭 지연을 판단하는 데 사용합니다
- **번들 분리 집계 (bundle_split_battles_in_stats)** — 한 전투의 다중 알라이언스를 상대별로 분리해 통계에 잡는 내부 정책 플래그입니다. 일반 설정 화면의 안전 스위치와는 다릅니다

### 길드 공개 페이지

- **길드 공개 프로필 (guild_profile_enabled)** — `/g/<slug>` 길드 공개 페이지를 켜고 끕니다
- **공개 항목 토글 (guild_profile_show_*)** — 멤버 수 / 전투 기록 / 리기어 통계 / 리더보드 / 어드민 명단 등 공개 페이지에 노출할 섹션을 항목별로 선택합니다. 운영진·개인 기여자·리기어 집계는 기본 비공개이며 관리자가 직접 켜야 합니다

> 토글 키 이름은 어드민 → 사용법 가이드 (인앱) 또는 사이트 설정 화면에서 친화 라벨로 확인할 수 있습니다.
