# 핵심 상태 복구

이 기능은 전체 데이터 백업이나 서버 이전 도구가 아닙니다. 사고가 났을 때 길드 운영을 다시 이어가는 데 필요한 **현재 핵심 상태**만 같은 길드 작업공간으로 되돌립니다.

## 복구 파일에 포함되는 것

- 길드원의 현재 포인트 잔액과 보류 중인 포인트 에스크로
- 상점·보급용 완제품 재고와 아직 처리되지 않은 재고 예약
- 미처리 환전, 상점 주문, 리기어, 제작, 개인거래 의무
- 위 의무를 다시 연결하는 데 필요한 최소 회원·이벤트·정책 참조

설정, 권한, 재사용 템플릿, 미래 이벤트, 완료·취소된 전체 이력, 과거 원장 전체, 통계, 알림, 캐시는 포함하지 않습니다. Discord 서버 이전도 지원하지 않습니다.

## 같은 길드만 복구할 수 있는 이유

파일에는 원본 작업공간 UUID와 복구용으로 고정된 Albion 길드 ID가 함께 들어갑니다. 서버는 파일을 발급할 때 백업 ID와 무결성 해시도 길드별로 등록합니다. 미리보기와 실제 적용 시 식별정보와 발급 기록이 모두 현재 길드와 일치해야 하며, 다른 길드 파일이나 식별정보를 고쳐 만든 파일을 선택하면 데이터는 변경되지 않습니다.

## 적용할 때 보장되는 것

서버는 적용 직전 상태를 먼저 안전 스냅샷으로 보관하고, 복구 전체를 하나의 원자 명령으로 실행합니다. 어느 한 단계라도 실패하면 잔액·재고·예약·의무 변경을 전부 롤백합니다. 성공하면 실행 ID, 전후 요약, 변경 diff가 포함된 복구 영수증과 감사 기록이 남습니다.

## 템플릿은 별도 패키지

이벤트·슬롯 구성을 다른 길드와 공유하려면 같은 화면의 **템플릿 패키지**를 사용합니다. 이 형식은 회원·재정·원장·재고 데이터를 담을 수 없으며, 같은 이름의 템플릿만 갱신합니다.

## 운영 팁

복구 파일은 정기적으로 내려받되, 실제 적용 전 미리보기에서 열린 의무와 재고 수량을 확인하세요. 복구 영수증과 감사 로그를 함께 보면 어떤 상태가 바뀌었는지 추적할 수 있습니다.
