# 백업 / 복원

백업은 길드 운영 데이터가 잘못 수정되거나, 설정을 크게 바꾸기 전에 되돌아갈 기준점을 남기는 기능입니다. 비개발자 운영자가 SQL 이나 별도 도구 없이 사이트 안에서 주요 데이터를 보존할 수 있게 하는 것이 목적입니다.

## 언제 쓰나

- 대규모 설정 변경 전
- 이벤트 템플릿, 상점, 권한을 정리하기 전
- 운영자가 바뀌어 이전 상태를 보관하고 싶을 때
- 문제 발생 후 복원 기준점을 확인해야 할 때

## 주의할 점

백업은 실수를 줄이는 안전장치이지, 모든 문제를 자동으로 해결하는 기능은 아닙니다. 복원은 기존 운영 데이터에 영향을 줄 수 있으므로 길드장 또는 권한을 받은 담당자만 실행해야 합니다.

## 운영 팁

큰 이벤트 시즌 전후, 상점 가격 정책 변경 전, 권한 체계 변경 전에는 백업을 남겨두는 것을 권장합니다. 복원 여부를 결정할 때는 감사 로그와 함께 확인하면 원인을 더 쉽게 찾을 수 있습니다.
