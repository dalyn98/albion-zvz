# Discord 운영 판단 가이드

관리자에게 Discord 명령은 "사이트를 대신 조작하는 곳"이 아니라 "운영 상황을 발견하고 올바른 화면으로 들어가는 곳"입니다. 아래 상황에 맞춰 사용하면 멤버 안내, 포인트 예외 처리, 신규 길드 온보딩을 반복 설명 없이 처리할 수 있습니다.

## 신규 길드가 시작할 때

사용할 것: `/agm setup`

봇을 막 초대한 길드라면 이 명령으로 설정 마법사를 만들거나 이어가세요. Discord 서버와 AGM 테넌트를 연결하고, 홈 길드·역할·채널·보상 정책을 셀프서브로 끝내는 출발점입니다.

주의할 점:

- 새 설정 생성에는 Discord 서버 관리자 또는 서버 관리 권한이 필요합니다.
- 이미 설정 중인 길드는 처음 설치한 사용자가 이어가는 흐름입니다.
- 설정이 active가 되면 같은 명령은 관리자 대시보드로 안내합니다.

## 신규 멤버 안내가 반복될 때

사용할 것: `/agm admin quick-publish`

멤버가 "사이트 어디예요?", "인증 어디서 해요?", "리기어 어디서 해요?"를 반복해서 묻는다면 Quick Starter Panel을 채널에 게시하세요. 인증, 이벤트, 내 정보, 리기어, 상점, 지갑, 가이드 버튼을 한곳에 고정해 둡니다.

운영 기준:

- 매번 `/agm quick`을 알려주는 대신, 신규 멤버가 들어오는 채널에 패널을 둡니다.
- 같은 채널에 이미 게시된 패널이 있으면 업데이트됩니다.
- 패널 문구는 짧게 두고, 자세한 설명은 문서와 사이트 화면으로 넘깁니다.

## 포인트 예외 보정이 필요할 때

사용할 것: `/agm admin points member delta memo`

이벤트 보상 누락, 잘못 지급된 포인트 정정, 운영 보정처럼 "왜 조정했는지"가 남아야 하는 상황에서 사용합니다. 포인트 총액을 직접 덮어쓰는 대신 장부에 새 항목을 추가합니다.

운영 기준:

- 일반 지급 루틴을 대체하지 않습니다.
- `delta`는 지급이면 양수, 회수면 음수입니다.
- `memo`에는 사람이 읽을 수 있는 사유를 남깁니다.
- 결과는 멤버 포인트와 감사 흐름에서 추적 가능해야 합니다.

## 킬봇/전투 알림이 이상할 때

사용할 것: `/agm admin killbot`

킬봇 피드가 안 보이거나 전투 알림 설정을 점검해야 할 때 사용합니다. Discord에서 문제가 먼저 보이므로, 명령은 가이드와 설정 화면으로 바로 보내는 역할을 합니다.

점검 순서:

1. Killbot 가이드로 기본 설정을 확인합니다.
2. 사이트의 killbot 설정 화면에서 채널, 토글, 권한을 확인합니다.
3. 전투 기록 자체가 누락된 문제라면 `/battles`와 killboard sync 상태를 같이 확인합니다.

## 관리자가 사이트를 계속 보고 있지 않을 때

사용할 것: 관리자 운영 알림 + Discord 승인 버튼 + 승인 배지

승인 대기, 상점 주문, 제작 납품, 미인증 멤버, 동기화 지연은 Discord 관리자 채널로 알림을 보냅니다. 리기어·환전·포인트 환전·상점 주문·이벤트 정산·제작 납품처럼 명확한 요청은 알림의 승인/거절 버튼으로 바로 처리할 수 있습니다.

운영 기준:

- 단순 승인/거절은 Discord 버튼으로 끝냅니다.
- 리기어는 실버 승인, 재고 출고, 제작 큐 전환 중 운영 의도에 맞는 버튼을 고릅니다.
- 가격 수정, 재고 세부 확인, 권한 변경, 정책 판단은 사이트에서 처리합니다.
- 알림은 "바로 처리할지, 어느 화면을 봐야 하는지"를 알려주는 신호입니다.

## 멤버 개인 업무가 기능 페이지를 방해할 때

사용할 것: `/agm quick`, `/agm me profile`, `/agm wallet balance`, 상단 내 정보 칩

멤버가 이벤트, 리기어, 상점 페이지를 보다가 개인 할 일 목록 때문에 본 기능을 보기 어려워지면 안 됩니다. 개인 상태는 내 정보, 지갑, 요청 내역, Discord 명령으로 분산합니다.

운영 기준:

- 이벤트 페이지는 이벤트 신청과 파티 확인에 집중합니다.
- 리기어 페이지는 보상 신청과 상세 확인에 집중합니다.
- 상점 페이지는 구매 흐름에 집중합니다.
- 개인 요약은 상단 상태 칩과 `/me`로 보냅니다.

## Discord와 사이트의 경계

| 상황 | Discord | 사이트 |
| --- | --- | --- |
| 멤버가 어디로 갈지 모름 | `/agm quick`, Quick Starter Panel | 실제 기능 화면 |
| 신규 길드 설정 시작 | `/agm setup` | 설정 마법사 |
| 포인트 예외 보정 | `/agm admin points` | 장부 / 감사 로그 확인 |
| 승인 대기 발견 | 관리자 알림 / 승인 버튼 | 승인 관리 |
| 이벤트 모집 시작 | 채널 공지 / 이벤트 버튼 | 이벤트 생성 / 파티 편집 |
| 개인 상태 확인 | `/agm wallet balance`, DM | 내 정보 / 지갑 / 요청 내역 |
