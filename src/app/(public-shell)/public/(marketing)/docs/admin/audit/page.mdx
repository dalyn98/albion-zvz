# 감사 로그

감사 로그는 누가 어떤 운영 변경을 했는지 추적하는 기록입니다. 권한을 여러 담당자에게 나눠 주는 길드일수록, “누가 승인했는지”, “누가 설정을 바꿨는지”를 확인할 수 있어야 합니다.

## 기록되는 종류

- 승인 / 거절 같은 처리 액션
- 권한과 설정 변경
- 상점, 재고, 사이펀처럼 재화와 관련된 운영 입력
- 핵심 상태 복구 같은 위험도가 높은 작업

## 왜 필요한가

길드 운영은 대부분 신뢰 기반이지만, 보상과 재화가 얽히면 작은 오해도 분쟁이 될 수 있습니다. 감사 로그는 담당자를 의심하기 위한 기능이 아니라, 운영자가 사실관계를 빠르게 확인하고 같은 실수를 줄이기 위한 장치입니다.

## 권장 운영 방식

권한을 줄 때는 담당 범위를 작게 나누고, 재화 관련 권한을 가진 담당자는 감사 로그를 함께 확인할 수 있는 운영 절차를 두는 것이 좋습니다. 특히 사이펀, 상점, 리기어 승인처럼 길드 자산과 연결된 기능은 로그를 주기적으로 확인하는 편이 안전합니다.
