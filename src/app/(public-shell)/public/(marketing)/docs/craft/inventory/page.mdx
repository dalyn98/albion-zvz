# 제작 인벤토리

`/craft/inventory` — 길드 제작자나 어드민이 미리 만들어 둔 장비 재고를 관리합니다. 재고가 있으면 청구가 들어왔을 때 즉시 박스에 넣어 끝낼 수 있습니다.

## 어떻게 동작하나

- 재고에 있는 장비는 청구가 들어올 때 그대로 박스에 넣고 끝 — 제작 사이클을 줄임
- 사전 재고가 0 인 장비를 즉시 시장에서 사 박스에 넣은 케이스는 별도 마크로 남아, 운영 지표로 관리할 수 있습니다


## 규칙과 정책

### 박스에 넣는 순간 재고에서 빠집니다

제작자가 장비를 박스에 넣어 청구자에게 전달하는 순간, 그 장비는 사실상 청구자 손에 넘어간 것으로 봅니다. 그래서 길드 재고는 박스 납품 시점에 즉시 차감되고, 청구자가 게임 안에서 픽업한 후에는 재고가 변하지 않습니다.

### "시장 즉시 구매" 는 표시됩니다

길드 재고를 잘 운영하면 시장 구매가 거의 없어야 합니다. 사전 재고 0 → 박스 직행이면 자동으로 마크가 남아, "이번 달 시장 의존률" 같은 운영 지표를 뽑을 수 있습니다.
