# 내 제작 작업

`/craft/my-tasks` — 제작자 권한을 받은 사람이 자기 큐만 모아서 보는 화면입니다. 큐의 일부를 자기 이름으로 잡고 (claim) 진행 상태를 관리합니다.

## 어떻게 동작하나

- 제작 큐에서 일부 장비를 "내 작업" 으로 잡습니다 (다른 제작자와 충돌 방지)
- 진행 / 완료 / 납품 상태로 내 작업 카드를 정리
- 완료된 작업은 박스 번호를 입력해 청구자에게 자동 안내


## 규칙과 정책

### 큐를 작업자별로 잡아서 충돌을 막습니다

제작자가 여러 명일 때 같은 장비를 둘이 동시에 만드는 일이 없도록, 큐의 일부를 본인 이름으로 잡는 단계를 둡니다. 잡힌 작업은 다른 제작자에게는 회색 처리돼 중복 제작을 방지합니다.
