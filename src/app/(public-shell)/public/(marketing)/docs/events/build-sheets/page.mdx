# 빌드표 모집

빌드표는 “이 슬롯에 어떤 장비를 입어야 하는지”를 이미지 중심으로 저장해 두는 기능입니다. 이벤트 템플릿이 파티 전체의 틀을 저장한다면, 빌드표는 로커스·저항 탱커·Engage DPS 같은 개별 장비 세트를 저장합니다.

## 언제 쓰나

- 대형 ZvZ 처럼 비슷한 무기와 방어구 조합을 여러 슬롯에 반복해서 넣을 때
- 이벤트마다 파티 틀은 달라도, 길드 표준 장비는 거의 같은 경우
- 길드원이 텍스트보다 장비 아이콘을 보고 자기 빌드를 빠르게 이해해야 할 때

## 관리자 흐름

1. 어드민 사이드바에서 **빌드표**를 엽니다.
2. 자주 쓰는 빌드를 새로 만들고 역할군, 카테고리, 장비, 스킬, 플랫 조건을 저장합니다.
3. 이벤트 생성/편집 화면에서 슬롯을 선택하고 빌드 팔레트를 엽니다.
4. 저장된 빌드 카드를 클릭하면 해당 슬롯에 빌드가 적용됩니다.

## 이벤트 모집 방식과의 관계

이벤트에는 세 가지 모집 방식이 있습니다.

- **슬롯 방식** — 기존처럼 슬롯을 직접 보고 신청합니다.
- **빌드표 방식** — 먼저 필요한 빌드표를 보여주고, 길드원이 맞는 빌드로 신청합니다.
- **하이브리드 방식** — 빌드표 기준으로 신청을 받고 운영진이 최종 파티와 슬롯을 확정합니다.

대형 ZvZ 에서는 빌드표/하이브리드 방식이 관리자의 반복 작업을 줄이고, 길드원에게도 “내가 뭘 입어야 하는지”를 더 명확하게 보여줍니다.

## 이벤트 템플릿과 다릅니다

이벤트 템플릿은 파티 수, 슬롯 위치, 전체 구성을 저장합니다. 빌드표는 개별 슬롯에 들어갈 장비 세트를 저장합니다. 둘을 같이 쓰면 “정모 기본 파티 구성”을 먼저 불러오고, 필요한 슬롯만 빌드 팔레트로 바꾸는 식으로 운영할 수 있습니다.
