# 슬롯 신청

슬롯 신청은 길드원이 가장 자주 쓰는 기능입니다. 이벤트 상세 페이지에서 본인이 맡을 역할 슬롯을 고르고 신청하면, 관리자는 전체 파티 구성을 보면서 확정하거나 조정합니다.

## 길드원이 하는 일

1. 이벤트 링크를 엽니다.
2. 가능한 슬롯을 확인합니다.
3. 본인이 맡을 역할에 신청합니다.
4. 필요한 경우 신청을 수정하거나 취소합니다.

전투가 이미 시작된 뒤에는 운영 정책에 따라 취소가 제한될 수 있습니다. 이 경우 신청은 참가 확정에 가깝게 처리됩니다.

## 관리자가 하는 일

관리자는 신청자 목록을 보며 슬롯을 확정하고, 빈 슬롯이나 중복 신청을 정리합니다. 여러 슬롯을 한 번에 붙여넣는 편집 흐름에서는 마우스로 올려둔 슬롯을 우선 채우는 방식이라, 중간 슬롯부터 빠르게 보정할 수 있습니다.

콜러나 관리자는 모집 중 특정 슬롯에 멤버를 직접 지정할 수도 있습니다. 멤버 검색은 참가 가능한 멤버를 우선 보여주고, 이미 다른 슬롯에 들어간 멤버는 상태를 구분해 표시합니다. 집결 시각에 운영이 시작되면 편성과 신청은 불변 스냅샷으로 잠기며, 실제 참가 예외는 종료 뒤 참가 마감 화면에서 조정합니다.

## 길드원 UX 기준

길드원은 “내가 신청했는지”, “어느 파티에 들어갔는지”, “전투 시간이 언제인지”를 바로 알아야 합니다. 이벤트 상세 페이지는 모집 공지보다 더 최신 상태여야 하며, Discord 메시지는 상세 페이지로 들어오는 입구 역할을 합니다.
