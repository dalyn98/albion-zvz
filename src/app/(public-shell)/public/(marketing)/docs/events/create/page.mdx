# 이벤트 생성 / 편집

이벤트는 관리자가 `/admin/dashboard` 에서 만드는 모집판입니다. 집결 시간, 집결 장소, 특이사항, 파티 슬롯 구성을 입력하고 저장하면 아직 길드원에게 공개되지 않은 초안으로 남습니다.

## 관리자가 먼저 정하는 것

- **집결 정보** — 날짜, 시간, 장소, 특이사항
- **파티 구성** — 파티 수, 파티별 슬롯, 역할군
- **슬롯 템플릿** — 자주 쓰는 조합은 템플릿으로 저장해 다음 이벤트에 재사용
- **참가예정 사용 여부** — 슬롯 확정 전 멤버가 가능한 역할군만 먼저 올릴 수 있게 할지
- **게스트 허용 여부** — 외부 참가자를 이벤트 단위로 초대할지

## 편집 중에는 초안으로 유지합니다

초안 상태에서는 운영자가 파티 수와 슬롯을 마음껏 바꿀 수 있습니다. 발행 전까지는 길드원에게 “신청 가능한 이벤트”로 보이지 않으므로, 불완전한 모집판이 노출될 걱정이 없습니다.

## 슬롯 템플릿을 쓰는 이유

ZvZ 조합은 길드마다 반복되는 패턴이 있습니다. 매번 새로 슬롯을 만들면 운영 시간이 길어지고 실수가 늘어나므로, 자주 쓰는 파티 구성을 템플릿으로 저장해 두는 것이 좋습니다.
