# 게스트 초대

게스트 초대는 길드원이 아닌 외부 참가자를 한 이벤트에만 제한해서 초대하는 기능입니다. 용병, 연합 외부 인원, 지인 길드 참가자가 전체 사이트를 보지 않고 자기 이벤트만 볼 수 있게 합니다.

## 접근 범위

게스트는 초대된 이벤트 상세 페이지만 볼 수 있습니다. 전체 멤버 목록, 리기어, 상점, 통계 같은 길드원 전용 기능은 차단됩니다.

## 초대 흐름

1. 관리자가 이벤트 상세 화면에서 게스트 초대 링크를 발급합니다.
2. 게스트가 링크를 열고 Discord 로그인을 합니다.
3. 해당 이벤트에 한정된 게스트 권한이 부여됩니다.
4. 만료 시간이 지나거나 관리자가 링크를 폐기하면 접근이 막힙니다.

## 왜 이벤트 단위인가

외부 인원이 운영을 도와주더라도 길드의 청구, 포인트, 상점, 통계까지 볼 이유는 없습니다. 이벤트 단위로 권한을 제한하면 필요한 협업만 열고 나머지 길드 데이터는 보호할 수 있습니다.
