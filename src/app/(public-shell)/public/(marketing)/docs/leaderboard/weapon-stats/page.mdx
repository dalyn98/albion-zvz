# 관측 무기 통계

이벤트 슬롯에 적힌 계획 무기와 전투에서 실제 관측된 장비는 별도 데이터입니다. 관측 통계는 최근 30일 공식·추적 전투의 `MainHand` 장비만 무기군으로 묶어 보여줍니다.

## 어떻게 동작하나

- 슬롯 신청·배정 기록은 **계획된 슬롯 무기**로 표시
- 킬보드 장비는 **실제 관측 무기군**으로 표시
- 표기는 티어·인챈트·알려진 아티팩트 접미사를 제거한 공통 무기군으로 통일
- 카운트는 **회원 + 무기군 + 전투당 1번** — 한 전투에서 킬·데스가 여러 번 기록돼도 1로만 셈
- 화면에 관측 기간과 전체 표본 수를 표시하며, 없으면 "관측 없음"으로 표시
- 단, 킬 로그 자체는 정확한 장비명을 그대로 보여줍니다 — 어떤 인챈트로 잡았는지 확인하고 싶을 때 손실되면 안 되니까요

## 규칙과 정책

### 계획과 관측을 섞지 않음

계획 슬롯은 편성 의도를 설명할 뿐 실제 착용을 증명하지 않습니다. 실제 관측 통계는 장비 근거가 있는 전투만 사용하며 계획 슬롯으로 빈 관측값을 채우지 않습니다.

### 통계는 "회원·무기군·전투당 1번"으로 셉니다

ZvZ 한 판에서 킬 이벤트가 10개 쌓여도 그 사람이 그 전투에서 그 무기를 "썼다" 는 사실은 1번입니다. 이벤트 수로 세면 격렬한 전투 한 번에 10배 가중되어 무기 트렌드가 왜곡되므로, 전투 단위로 묶어 카운트합니다.

### 숙련도나 실력 판정이 아님

관측 빈도는 어떤 장비가 기록에 나타났는지를 설명할 뿐 숙련도·역할 수행·실력을 평가하지 않습니다. 포인트·보상·리기어·권한·참가 자격·자동 편성에도 연결되지 않습니다.
