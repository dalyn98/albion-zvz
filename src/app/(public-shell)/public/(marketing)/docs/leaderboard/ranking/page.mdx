# 성취 리더보드

`/leaderboard`는 공식·추적 전투에서 직접 확인된 독립 지표별 상위 기록을 보여줍니다. 운영진의 회원 평가표나 여러 지표를 합친 종합 점수가 아닙니다.

## 어떻게 동작하나

- 킬 / 전투 참여 / 생존률 / K/D / 승률을 서로 합치지 않고 별도 표시
- 주간 / 최근 30일 / 최근 2년의 정확한 집계 시작·종료일 표시
- 활성 앱 길드원 모집단, 지표별 Top 10, 최소 표본을 화면에서 설명
- 멤버 카드 클릭 → 멤버 상세 페이지로 이동

## 규칙과 정책

### 긍정적 상위 기록만 표시

지표별 상위 10명만 표시하며 하위 순위·미달자 목록은 만들지 않습니다. 생존률·K/D·승률은 작은 표본의 우연을 성취처럼 보이지 않게 최소 5회의 관련 관측이 있어야 합니다.

### 목적이 다른 데이터는 합치지 않음

영구 성취, 운영 통계, Menhera 콘텐츠 준수는 각자의 근거와 목적이 다릅니다. 리더보드 값은 포인트·보상·리기어·권한·참가 자격·자동 편성·콘텐츠 준수 상태를 바꾸지 않습니다.

### 공개는 별도 선택

길드 공개 프로필의 개인 기여 목록과 공개 활동 링크의 성취는 활동 공개만으로 노출되지 않습니다. 회원이 개인 리더보드·성취 공개를 별도로 선택해야 합니다.
