# 게스트 시스템

길드원도, 동맹 길드원도 아닌 외부 사람을 한 이벤트에 한정해서 초대하는 시스템입니다. 용병이나 친한 다른 길드 인원이 우리 ZvZ 한 번에 합류할 때 쓰입니다.

## 어떻게 동작하나

이벤트 상세 화면에서 관리자가 "게스트 초대 링크" 를 발급합니다. 그 링크로 들어와 디스코드 로그인을 한 사람은 게스트로 등록되고, 해당 이벤트 페이지만 볼 수 있습니다.

- 다른 주소 (전체 멤버 목록, 리기어, 상점 등) 로 들어가면 본인이 초대된 이벤트 페이지로 자동 이동됩니다.
- 게스트는 이벤트 슬롯 신청 / 출석 체크만 가능하고, 길드원 전용 기능 (리기어 청구, 상점 구매 등) 은 차단됩니다.
- 초대 링크는 이벤트 단위로 발급되며 만료 시간이 지나거나 관리자가 폐기하면 다음 로그인부터 막힙니다.

## 규칙과 정책

### 게스트는 길드원·연합 인원과 분리됩니다

길드 동기화로 들어오는 알비온 길드원, 동맹 길드 데이터에 포함된 인원과 게스트는 데이터상 따로 관리됩니다. 게스트는 길드 통계·리더보드에 잡히지 않고, 길드원 명단에도 들어가지 않습니다.

### 이벤트 단위 권한

길드 운영을 도와줄 외부 사람이라도 사이트 전체 권한을 줄 이유는 없습니다. 게스트는 자기가 초대된 이벤트 한 건만 볼 수 있게 격리되어 있어, 길드 청구·상점·통계는 길드원 전용으로 유지됩니다.
