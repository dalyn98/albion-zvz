# 멤버 상세

한 길드원의 활동 프로필입니다. 공통 활동 정보와 개인·운영 정보를 한 화면에 무조건 합치지 않고, 보는 사람의 업무 권한에 따라 필요한 영역만 불러옵니다.

## 어떻게 동작하나

`/members/[디스코드ID]` 에서 다음 정보를 봅니다.

- 길드 내부 공통: 안전한 알비온 캐릭터 요약, 참여·역할·관측 무기·전투 활동
- 본인: 자기 포인트·환전, 리기어·영상, 체험·부재와 신원 상세
- 재정 담당: 포인트·환전 정보
- 리기어 담당: 신청, 판정 메모와 제출 영상
- 회원 관리 담당: 체험·부재, 신원 검토와 예외 회원 상세

사이트 미연결 알비온 캐릭터 상세는 회원 관리 권한이 있는 운영진만 `/admin/dashboard/members/albion/[캐릭터ID]` 에서 확인할 수 있습니다.

## 규칙과 정책

### 목록 권한은 개인 업무 정보 권한이 아님

길드원 명부를 볼 수 있다는 이유만으로 다른 회원의 포인트, 리기어 증빙, 영상, 준수 상태, 운영 메모를 받을 수 없습니다. 서버가 각 영역을 권한별로 조회하며, 권한이 없는 영역은 빈 값으로 보내는 대신 응답 자체에서 제외합니다.

### 직접 주소도 같은 검사를 거침

검색 결과, Discord 연결, 알비온 로스터 링크와 직접 입력한 주소 모두 현재 길드 소속·회원 상태·업무 권한을 서버에서 다시 확인합니다. 탈퇴·신원 검토 대상은 일반 상세에서 열리지 않고 회원 운영 명부로 분리됩니다.

### 외부 공유 프로필은 더 좁음

본인이 만든 공개 활동 링크에는 개인 경제·신청 증빙·운영 정보와 이벤트·킬의 정확한 시간선이 포함되지 않습니다. 알비온 캐릭터명과 집계된 활동 지표만 공유합니다.
