# 멤버 목록

`/members` 에 사이트의 모든 길드원이 카드로 나열됩니다. 권한 / 상태로 필터하고, 카드를 누르면 상세로 들어갑니다.

## 어떻게 동작하나

- 디스코드 닉네임 / 알비온 캐릭터 / 권한 / 마지막 활동을 카드 한 장에 요약
- 이름·권한 (어드민 / 제작자) · 인증 여부로 검색 / 필터
- 카드 클릭 → 멤버 상세 페이지로 이동


## 규칙과 정책

### 어드민과 제작자 권한은 별개

길드 어드민 = 사이트 정책·승인을 다루는 사람, 제작자 = 길드 제작 큐를 처리하는 사람. 두 역할은 보통 다른 사람이라 권한도 분리되어 있어, 한쪽만 가진 사람도 자기 영역만 깔끔히 쓸 수 있습니다.
