# 멤버 목록

`/members` 는 현재 활동 중인 길드원을 찾는 길드 내부 명부입니다. 카드를 누르면 활동 프로필로 이동합니다.

## 어떻게 동작하나

- 현재 활동 중이며 신원 검토 문제가 없는 사이트 연결 길드원만 표시
- 이름, 신청·배정 기록, 계획 편성 역할·무기군을 카드에 요약
- 이름·역할·계획 무기군으로 검색·필터
- 카드 클릭 → 멤버 상세 페이지로 이동

## 규칙과 정책

### 예외 인원은 회원 운영 명부에서 관리

게스트, 사이트와 연결되지 않은 알비온 로스터, 탈퇴 회원, 신원 검토 대상은 일반 명부에 섞이지 않습니다. `회원 관리` 권한이 있는 운영진만 `/admin/dashboard/members` 에서 이 예외를 확인하고 처리합니다.

### 목록은 활동 탐색용

포인트, 리기어 신청·영상, 준수 상태, 운영 메모, 체험·부재 상태는 일반 목록에 표시하지 않습니다. 각 업무 정보는 본인 또는 해당 업무 권한을 가진 운영진에게만 열립니다.
