# 교전 상세에서 보기

자동 구분된 교전 하나에 직접 연결된 길드원의 킬·데스 로그를 봅니다. 원본 battle 전체의 로그를 섞지 않아 앞뒤의 다른 싸움이 같은 교전처럼 보이지 않습니다.

## 어떻게 동작하나

`/battles/[교전ID]` 에서 교전의 종합 정보를 봅니다.

- 직접 K/D와 킬페임으로 계산된 교전 판정
- 판정 대상·개입·기타로 구분된 상대별 근거
- 해당 교전에 배정된 길드원 킬·데스 로그
- 원본 전투와 수집 이벤트의 일치 상태


## 규칙과 정책

### 로그와 판정 근거의 범위

사실 로그에는 개입·기타 이벤트도 남을 수 있지만 공식 결과에는 판정 대상으로 분류된 직접 이벤트만 사용합니다. 통계와 리기어 연결도 같은 교전 이벤트 범위를 사용하므로 원본 battle의 다른 싸움이 섞이지 않습니다.
