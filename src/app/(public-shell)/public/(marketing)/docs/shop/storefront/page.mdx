# 상점 화면

`/shop` 에서 상품 카드를 보고 주문 요청을 보냅니다. 포인트와 재고는 관리자가 주문을 승인하는 시점에 함께 차감됩니다.

## 어떻게 동작하나

- 아이콘 / 이름 / 적용된 환율의 가격 (포인트)
- 주문을 보내면 관리자 승인 대기 상태가 됩니다
- 관리자가 승인하면 포인트가 차감되고 재고가 줄어듭니다
- 수령 방법은 길드가 `/shop` 상단 전달 공지와 관리자 메모로 안내합니다


## 규칙과 정책

### 1:1 (포인트 = 실버) 이 기본

포인트와 실버 가격을 멤버가 머릿속에서 환산하지 않게 하려는 의도입니다. 환율 100% 일 때 5M 실버짜리 장비는 5M 포인트 — 실버 시세를 그대로 인식하면 됩니다. 할인을 줄 때만 환율을 손대게 해서 평소 의사결정이 단순합니다.
