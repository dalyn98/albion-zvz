# 환율 조정 (어드민)

전역 환율 한 개로 전체 상품 가격을 조절합니다. 100% 면 실버 가격 그대로 포인트 가격, 50% 면 절반 가격에 판매.

## 어떻게 동작하나

```
포인트 가격 = 실버 시세 × (환율 / 100)
```

어드민이 환율을 한 번 바꾸면 모든 상품의 포인트 가격이 일관되게 갱신됩니다. "이번 달은 50% 할인" 같은 시즌 이벤트도 환율 한 줄로 운영합니다.


## 규칙과 정책

### 환율과 할인율은 같은 값입니다

"환율" 과 "할인율" 은 같은 숫자를 두 가지 관점으로 부르는 이름입니다. 100% = 시세 1:1 = 할인 없음, 50% = 시세 절반에 판매 = 50% 할인. 화면에서도 "환율 / 할인율" 로 표시하고, 내부에서도 같은 multiplier 한 개로 계산해서 가격 변경 한 번에 모든 상품이 일관되게 갱신됩니다.

### 환율은 전역 한 개

상품마다 환율을 따로 두면 가격표가 너무 복잡해지고, "이번 주 50% 할인" 같은 시즌 이벤트 운영을 못 합니다. 전역 한 개로 두고 모든 상품에 곱하는 방식이 "리기어 청구를 자주 했더니 금고가 빈다 → 환율을 30% 로 낮춰 회전을 늦춘다" 같은 운영 의도를 가장 직관적으로 반영합니다.
