# 박스 픽업

상점에서 주문한 장비는 관리자 승인 후 길드가 정한 방식으로 받습니다. 길드 금고 박스 픽업을 쓰는 길드는 `/shop` 전달 공지나 관리자 메모로 박스 위치 / 도시 정보를 안내합니다.

## 어떻게 동작하나

멤버가 주문을 보내면 승인 대기 상태가 됩니다. 관리자가 실제 재고와 전달 가능 여부를 확인해 승인하면 포인트와 재고가 차감되고, 이후 길드 운영 방식에 맞춰 박스 위치 / 도시 / 전달 채널을 안내합니다. 사이트에는 상점 주문용 별도 수거 확인 액션이 없습니다.


## 규칙과 정책

### 알비온은 직접 양도가 제한적입니다

알비온은 게임 안에서 직접 아이템을 양도할 방법이 제한적입니다. 어드민이 "X 캐릭터에게 보낸다" 라고 약속한 박스 (Bank chest) 에 장비를 두고 멤버가 픽업하는 흐름이 자연스러워서, 사이트는 그 흐름을 그대로 표현합니다.
