탭마다 보는 순서

  • 먼저 어느 메뉴에서 시작하는지 확인합니다.
  • 그다음 화면에서 눌러야 할 순서만 따라갑니다.
  • 마지막으로 완료 표시나 관리자에게 보낼 정보를 확인합니다.
가입 직후

로그인과 캐릭터 연결을 끝내는 순서

사이트 첫 사용자는 홈에서 로그인하고, 내정보에서 캐릭터와 포인트 영역을 확인하면 됩니다.

먼저 갈 곳 길드 사이트 홈 → Discord 로그인 → 내정보
1

어디서 하나요

길드 사이트 홈에서 Discord 로그인 버튼을 누릅니다.

2

어떻게 하나요

로그인 후 안내되는 캐릭터 인증 화면에서 Albion 닉네임을 연결합니다.

3

무엇을 확인하나요

내정보에서 캐릭터 이름, 포인트, 요청 상태가 보이면 준비 완료입니다.

!

안 될 때다른 길드 화면이 보이면 로그아웃 후 현재 길드 도메인에서 다시 로그인하세요.

이벤트 당일

이벤트 상세에서 신청하고 상태를 확인합니다

홈의 이벤트 카드 또는 이벤트 목록에서 해당 이벤트를 열고, 슬롯 신청 후 내 이름이 표시되는지 확인하세요.

1

어디서 하나요

홈 이벤트 카드나 이벤트 목록에서 오늘 참여할 이벤트를 엽니다.

2

어떻게 하나요

집결 시간과 CTA를 확인한 뒤, 무기와 역할이 맞는 슬롯을 선택해 신청합니다.

3

무엇을 확인하나요

내 이름이나 신청 상태가 슬롯에 표시되는지 확인합니다. 잘못 신청했다면 같은 화면에서 취소 후 다시 신청합니다.

!

안 될 때이벤트가 닫혔거나 신청 시간이 지난 경우 슬롯 변경이 제한될 수 있습니다. 이벤트 이름과 화면 캡처를 관리자에게 보내세요.

개인 대시보드

내정보에서 포인트와 요청 상태를 확인합니다

상점 구매, 환전, 리기어 처리 상태가 궁금하면 먼저 내정보를 여세요.

포인트상점, 환전, 보상 기준 잔액
요청리기어, 환전, 제작 처리 상태
설정캐릭터와 Discord DM 상태

사이드바의 내 정보 섹션에서 내정보 또는 지갑 화면을 엽니다.

2

어떻게 보나요

포인트 잔액, 리기어, 환전, 제작 요청 목록을 위에서부터 확인합니다.

3

무엇을 확인하나요

요청이 대기, 처리 완료, 반려 중 어디에 있는지 확인합니다.

!

안 될 때캐릭터를 바꿨거나 기록이 맞지 않으면 내정보의 인증 화면에서 다시 연결하세요.

사망 후

블랙존 ZvZ 사망 후 리기어 화면에서 이벤트와 사망 기록을 맞춰 제출하세요.

1

어디서 하나요

사이드바의 리기어 신청 또는 이벤트 상세의 내 상태 영역에서 시작합니다.

2

어떻게 하나요

사망한 이벤트를 고르고 자동 사망 기록이 보이면 그 기록으로 신청합니다.

3

무엇을 확인하나요

제출 후 내정보 또는 리기어 목록에서 요청이 대기 상태로 생겼는지 확인합니다.

!

안 될 때자동 기록이 없으면 잠시 기다리거나 수동 신청을 사용합니다. 오버차지, 제외 부위, 지급 방식은 길드 정책을 따릅니다.

아이템 구매는 상점, 실버 지급 요청은 내정보의 요청 영역, 사이펀 잔량은 내정보 또는 사이펀 화면에서 확인합니다.

어디서 하나요

2

어떻게 하나요

상점에서는 상품을 선택해 구매하고, 실버가 필요하면 환전 요청을 제출합니다.

3

무엇을 확인하나요

주문 또는 환전 요청이 내정보의 요청 목록에 생겼는지 확인합니다.

!

안 될 때아이템 수령 방식과 환전 처리 시간은 길드 공지를 따르세요. 주문명과 요청 시각을 관리자에게 보내면 확인이 빠릅니다.

보내면 좋은 정보 계정, 캐릭터, 이벤트 이름, 문제 화면 스크린샷
1

어디서 막혔나요

현재 길드 도메인과 메뉴 이름을 확인합니다. 예: 이벤트 상세, 리기어 신청, 상점.

2

어떻게 했나요

누른 버튼, 선택한 이벤트, 신청한 슬롯이나 요청 종류를 적습니다.

3

무엇을 보내나요

계정, 캐릭터명, 이벤트 이름, 발생 시각, 화면 스크린샷을 함께 보냅니다.
