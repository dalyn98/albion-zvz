사진 보고 바로 찾기

어떤 메뉴를 눌러야 하는지 사진으로 확인하세요

각 탭은 실제 화면 위치에 번호를 표시했습니다. 번호 설명대로 클릭하고, 이미지가 작으면 눌러서 크게 보세요.

보는 순서

  • 필요한 기능 탭을 먼저 선택합니다.
  • 사진의 번호 위치를 보고 같은 번호 설명을 따라갑니다.
  • 완료 확인과 안 될 때 보낼 정보를 마지막에 확인합니다.
로그인 후

처음 들어오면 이벤트와 내 정보를 먼저 확인합니다

기본 화면에서 이벤트를 열고, 왼쪽 메뉴로 리기어 신청과 내 정보로 이동합니다.

기본 이동 이벤트 → 리기어 신청 → 내 정보
  1. 1

    이벤트 메뉴왼쪽 사이드바의 달력 아이콘을 누르면 참여할 이벤트 목록이 열립니다.

  2. 2

    가이드 다시 열기오른쪽 위 가이드 버튼에서 이 사용법을 다시 열 수 있습니다.

  3. 3

    내 정보로 이동왼쪽 아래 지갑 아이콘을 누르면 포인트와 환전 화면으로 이동합니다.

!

로그인이 안 보일 때로그인 전이면 Discord 로그인 버튼이 먼저 보입니다. 다른 길드 화면이 보이면 로그아웃 후 현재 길드 주소에서 다시 로그인하세요.

이벤트 당일

이벤트를 열고 원하는 슬롯에 신청합니다

이벤트 목록에서 전투 카드를 열고, 역할과 장비를 확인한 뒤 빈 슬롯의 신청 버튼을 누릅니다.

  1. 1

    이벤트 카드 열기왼쪽 이벤트 메뉴에서 참여할 전투 카드를 누릅니다.

  2. 2

    빈 슬롯 신청역할과 장비를 확인하고, 비어 있는 슬롯 카드의 신청 버튼을 누릅니다.

  3. 3

    신청 상태 확인내 이름이 슬롯이나 오른쪽 전체 신청 현황에 보이면 신청된 상태입니다.

!

안 될 때이벤트가 닫혔거나 신청 시간이 지난 경우 슬롯 변경이 제한될 수 있습니다. 이벤트 이름과 화면 캡처를 관리자에게 보내세요.

내 정보

포인트와 환전은 내 정보에서 확인합니다

포인트 잔액, 환전 신청, 최근 처리 내역을 확인하려면 내 정보의 포인트와 환전 영역으로 이동하세요.

잔액상점과 환전에 쓸 포인트
환전실버 지급 신청과 대기 상태
신청 내역리기어, 환전, 기부 처리 기록
  1. 1

    내 정보 열기왼쪽 사이드바의 지갑 아이콘을 누르거나, 상단 내 정보 칩에서 포인트 항목을 누릅니다.

  2. 2

    잔액 확인포인트와 환전 영역에서 현재 잔액, 대기 환전, 누적 흐름을 확인합니다.

  3. 3

    환전 신청실버가 필요하면 환전 신청 버튼을 누릅니다. 처리 상태는 신청 내역에서 확인합니다.

!

잔액이 안 맞을 때최근 리기어, 상점 주문, 환전이 아직 처리 중일 수 있습니다. 신청 내역의 상태와 시간을 함께 확인하세요.

사망 후

리기어 신청에서 자동 청구와 수동 청구를 선택합니다

블랙존 ZvZ 사망 후 리기어 신청 화면을 열고, 자동 기록이 있으면 자동 청구로, 없으면 수동 청구로 제출합니다.

  1. 1

    리기어 신청 열기왼쪽 사이드바의 방패 아이콘 또는 리기어 신청 메뉴를 누릅니다.

  2. 2

    자동 청구 보기자동 리기어 확인 카드에서 자동 청구 보기를 눌러 생성된 신청을 확인합니다.

  3. 3

    수동 청구 작성자동 기록이 없으면 수동 청구 작성 버튼을 눌러 사망 기록과 스크린샷을 제출합니다.

!

완료 확인제출 후 내 정보 또는 리기어 화면의 내 신청 내역에서 대기 상태가 생겼는지 확인합니다. 오버차지, 제외 부위, 지급 방식은 길드 정책을 따릅니다.

포인트 사용

길드 상점에서 아이템을 담고 주문합니다

아이템 구매는 길드 상점에서 진행합니다. 포인트를 실버로 바꾸는 환전은 내 정보의 포인트와 환전 영역에서 신청합니다.

상점포인트로 아이템 주문
환전내 정보에서 실버로 신청
내 주문대기/승인 상태 확인
  1. 1

    길드 상점 열기왼쪽 사이드바의 쇼핑백 아이콘 또는 길드 상점 메뉴를 누릅니다.

  2. 2

    아이템 담기필요한 아이템 타일을 클릭하면 오른쪽 장바구니에 담깁니다.

  3. 3

    주문 요청장바구니의 총액과 잔액을 확인한 뒤 주문 요청 버튼을 누릅니다.

!

주문 후 확인주문 처리 시간과 수령 방식은 길드 공지를 따릅니다. 주문명과 요청 시각을 관리자에게 보내면 확인이 빠릅니다.

막혔을 때

막힌 화면과 누른 버튼을 같이 보냅니다

관리자가 바로 확인할 수 있도록 메뉴 이름, 누른 버튼, 화면 상태를 한 번에 보내세요.

보내면 좋은 정보 계정, 캐릭터, 이벤트 이름, 문제 화면 스크린샷
  1. 1

    메뉴 이름 확인왼쪽 메뉴에서 현재 위치를 확인합니다. 예: 이벤트, 리기어 신청, 길드 상점, 내 정보.

  2. 2

    누른 버튼 적기누른 버튼 이름, 선택한 이벤트, 신청한 슬롯이나 요청 종류를 적습니다.

  3. 3

    스크린샷 보내기계정, 캐릭터명, 발생 시각, 화면 스크린샷을 함께 보내면 확인이 빠릅니다.

!

권한 문제메뉴가 보이지 않으면 권한이나 길드 가입 상태 문제일 수 있습니다. 현재 URL과 보이지 않는 메뉴 이름을 함께 보내세요.
