Discord 채널에 알비온 킬·데스를 자동 공지하는 킬봇

킬봇은 알비온 공식 이벤트 API를 주기적으로 확인해 우리 길드가 관여한 킬과 데스를 Discord 채널에 embed 메시지로 전송합니다. 대시보드에서 세부 설정을 관리하고, Discord slash command로 빠르게 켜고 끌 수 있습니다.

관리자 킬봇 설정 열기 킬보드 문서 보기

요약

5분 주기 cron
  • 대상 홈 길드가 킬러 또는 피해자인 Albion killboard event
  • 전송 위치 설정된 Discord 텍스트 채널
  • 필터 최소 fame, 킬 포함, 데스 포함, 내부 길드 킬 제외
  • 중복 방지 guild_id + event_id + feed_type 기준 1회만 전송
  • 관리 권한 앱 관리자 또는 일반 설정 권한, Discord는 서버 관리 권한

대시보드 설정

경로는 /admin/dashboard/killbot 입니다. 앱 안에서는 관리자 사이드바의 킬봇 메뉴로 접근합니다.

홈 길드와 알비온 서버 확인

킬봇은 테넌트의 albion_server, albion_home_guild_id, albion_home_guild_name 설정을 사용합니다. 값이 없으면 실제 킬·데스 알림을 보낼 수 없습니다.

Discord 채널 선택

봇이 접근 가능한 서버 채널 중 알림을 받을 채널을 선택합니다. 채널 목록을 불러오지 못하면 Discord 연동 또는 봇 권한을 먼저 확인합니다.

알림 조건 저장

킬봇 알림 사용, 최소 fame, juicy 기준 fame, 우리 길드 킬 알림, 우리 길드 데스 알림을 정하고 저장합니다.

테스트 전송

저장 후 테스트 전송을 눌러 Discord 메시지가 실제 채널에 도착하는지 확인합니다. 테스트도 최근 전송 기록에 남습니다.

Discord slash command

/killbot 명령은 Discord 서버 안에서만 동작합니다. 응답은 모두 ephemeral이라 명령을 실행한 사람에게만 보입니다.

명령 동작 권한/주의
/killbot setup 현재 Discord 채널을 알림 채널로 저장하고 킬봇을 켭니다. Discord 관리자 또는 서버 관리 권한이 필요합니다.
/killbot status 현재 ON/OFF, 채널, 최소 fame, 대시보드 링크를 보여줍니다. 채널이 없으면 setup 또는 대시보드 설정을 안내합니다.
/killbot test 설정된 채널 또는 현재 채널로 테스트 embed를 전송합니다. 전송 실패 시 Discord 권한, 봇 토큰, 채널 접근 권한을 확인합니다.
/killbot pause 채널 설정은 유지하고 킬봇만 끕니다. 재개 전까지 cron이 해당 길드 알림을 보내지 않습니다.
/killbot resume 기존 채널 또는 현재 채널로 킬봇을 다시 켭니다. 저장된 채널도 현재 채널도 없으면 실행할 수 없습니다.

동작 방식

현재 구현은 별도 Discord webhook이 아니라 bot token으로 Discord channel message를 직접 보냅니다.

1. cron 실행 /api/cron/killbot-feed가 5분마다 실행됩니다.
2. 활성 설정 조회 enabled=true이고 채널이 있는 길드만 처리합니다.
3. Albion event 조회 서버별 최근 이벤트 최대 51개를 가져옵니다.
4. 킬/데스 분류 홈 길드가 killer면 kill, victim이면 death로 분류합니다.
5. Discord 전송 중복 ledger 예약 후 embed를 전송하고 결과를 기록합니다.

포함 알림 대상

  • 홈 길드가 킬러인 이벤트, include_kills=true인 경우
  • 홈 길드가 피해자인 이벤트, include_deaths=true인 경우
  • TotalVictimKillFame이 최소 fame 이상인 이벤트
  • 홈 길드 ID가 우선 매칭되며, 없으면 홈 길드 이름으로 fallback 매칭

제외 알림 제외

  • 홈 길드가 킬러도 피해자도 아닌 이벤트
  • 킬러와 피해자가 모두 홈 길드인 내부 킬
  • 최소 fame 미만 이벤트
  • 이미 같은 event_id와 feed_type으로 기록된 이벤트
Discord embed 예시 Kill
Juicy Kill: HomeCaller vs EnemyDPS
Menhera scored a kill.
Fame 1,250,000
Event ID 123456789
Battle 987654

메시지 내용 embed 필드

  • 제목: Kill 또는 Death, 기준 이상이면 Juicy prefix
  • 링크: 알비온 공식 killboard 이벤트 URL
  • 필드: Fame, Event ID, Battle ID, Killer, Victim
  • 색상: 킬은 초록, 데스는 빨강

운영 확인

대시보드의 동작 상태와 최근 전송 표는 운영 중 문제를 확인하는 1차 화면입니다.

상태 마지막 확인

last_polled_at은 cron이 해당 길드 설정을 마지막으로 처리한 시각입니다. 값이 갱신되지 않으면 cron 인증 또는 배포 설정을 확인합니다.

전송 마지막 전송

last_sent_at은 Discord 메시지가 성공적으로 전송된 마지막 시각입니다. 조건에 맞는 이벤트가 없으면 갱신되지 않을 수 있습니다.

오류 마지막 오류

Discord API 실패, 봇 토큰 누락, 채널 권한 문제, 홈 길드 설정 누락은 last_error에 남습니다.

전송 ledger

killbot_deliveries는 전송 시도 이력을 저장합니다. 최근 20건이 대시보드에 표시되며 상태는 pending, sent, failed, skipped 중 하나입니다.

현재 제한 사항

운영자가 기대치를 맞추기 위해 알아야 하는 구현상 제한입니다.

최근 이벤트 51개 기준

알비온 이벤트 조회는 서버별 최근 51개를 사용합니다. 5분 사이 이벤트가 매우 많이 발생해 51개를 넘으면 오래된 일부 이벤트는 킬봇 알림에서 빠질 수 있습니다.

홈 길드 단위 매칭

현재 분류는 홈 길드 ID 또는 홈 길드 이름 기준입니다. 동맹 전체 killfeed가 아니라 해당 길드의 킬·데스 알림으로 이해해야 합니다.

대시보드 role mention 미노출

데이터 모델에는 mention_role_id가 있지만 현재 관리자 화면과 /killbot 명령은 역할 멘션 설정 UI를 제공하지 않습니다.

Discord 권한 의존

봇이 채널을 볼 수 없거나 메시지를 보낼 수 없으면 설정 저장은 되어도 실제 전송은 실패합니다. 테스트 전송으로 반드시 확인합니다.

문제 해결 체크리스트

알림이 오지 않을 때는 아래 순서로 확인합니다.

설정 확인

  • 킬봇 알림 사용이 켜져 있는지 확인
  • Discord 채널이 선택되어 있는지 확인
  • 홈 길드와 알비온 서버 설정이 완료되어 있는지 확인
  • 최소 fame이 너무 높지 않은지 확인
  • 킬 알림 또는 데스 알림이 필요한 방향으로 켜져 있는지 확인

전송 확인

  • 테스트 전송이 성공하는지 확인
  • 최근 전송 표에 failed 상태가 있는지 확인
  • 마지막 오류에 Discord API 또는 채널 권한 오류가 있는지 확인
  • 같은 이벤트가 이미 전송된 것은 아닌지 확인
  • Discord 서버에서 slash command 권한이 있는 계정으로 실행했는지 확인
